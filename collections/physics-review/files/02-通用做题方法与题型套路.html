通用做题方法与题型套路（三章通用）

下载 PDF离线 / 打印版

这三章的题，90% 都能归到下面 8 个套路里。做不出来的题，通常是第一步"识别题型"就错了，而不是数学不会。 建议：先读第 1 节的"暗示词 → 方法"对照表，再读具体套路，最后背第 9 节的格式模板。

1 题型识别：先看题目"给了什么、问了什么"

1.1 三步定位法

  1. 看场源形状 → 决定用什么方法求场 - 点电荷 / 几个点电荷 → 场强叠加（矢量），电势叠加（标量） - 规则形状连续带电体（棒、环、盘）→ 微元积分（能积分就积分，不能积分考虑结论） - 球 / 柱 / 平面且"均匀带电" → 高斯定理 - 已有导体 → 先求电荷分布（可能来自静电平衡、接地、感应）
  2. 看有没有"物质" → 是否出现导体、介质、、、电荷重新分布 - 有 → 走第 4、5、6 节（导体/电容/能量套路） - 没有 → 纯真空场问题，走第 2、3 节
  3. 看问的是什么量 → 决定最终一步 - 问 → 通常到"大小 + 方向"结束 - 问 、电势差 → 需要 的分段表达式再积分 - 问做功、能量 → 能量式或

2 套路 A：求电场强度

A1 点电荷（少数几个）——矢量叠加

  1. 画图，标出每个电荷到待求点的距离与方向。
  2. 写出每个场强的大小：。
  3. 分解到坐标轴（不要直接算矢量和），对称性会让某些分量自动抵消。
  4. 合成：，方向 。

常见陷阱：一维共线时把方向搞反。建议统一规定"向右为正"，负电荷的场强代入负号。

A2 连续带电体——微元法（五步）

  1. 取微元 或 或 。
  2. 写微元在场点的大小 。
  3. 利用对称性判断哪些分量抵消（例：圆环轴线上垂直轴的分量全抵消；直棒中垂线上平行棒方向的分量抵消）。
  4. 只对保留下来的分量积分，把积分变量统一成一个变量（常用角度或坐标 ），并写出积分限。
  5. 得出结果后做极限检验： 时是否退化为点电荷公式； 时是否符合常识。

记住三个"模板积分"： 圆环、圆盘、直棒三类题的积分本质都是第一条。

A3 高对称——高斯定理（三步，缺一步就扣分）

  1. 说明对称性："由球（柱/面）对称性，高斯面上各点场强大小相等，方向沿法线方向。"
  2. 选高斯面：球对称→同心球面；轴对称→同轴圆柱面（含端面）；面对称→对称的长方体（两底面平行带电面）。
  3. 写通量、代电荷：内，解出 。
内球面：圆柱侧面：为柱高平面：为底面积

判据：如果高斯面上的 不一定处处相等，就不能用高斯定理求 （但通量仍可算）。这是最常见的误用。

A4 叠加/补偿法（技巧题）

把"带孔的板""缺一角的环"看成"完整物体 + 负电荷物体"的叠加。如无限大带电平板上挖掉一个半径 的圆盘：全板圆盘。

B3 电势零点怎么取

  • 有限带电体：取无穷远（简单）。
  • 无限长直线、无限大平面：不能取无穷远（积分发散），改取某处（如 ）为零，或用"电势差"表述。
  • 导体接地：该导体 ，这本身就是条件，用来反解电荷。

B4 电势差 / 做功 / 电势能

符号规则：正电荷沿电场线方向移动，电场力做正功，电势能减少。代入时保留 的符号，就不容易错。

4 套路 C：导体静电平衡（电荷分布优先）

C1 万能前三步

  1. 判断静电平衡：导体内部 ，整块导体等势 → 立刻能写出"某两个点电势相等"。
  2. 分配电荷：写出每一个表面的电荷（用 内 表示），再叠加求场。 - 实心导体：电荷全在外表面。 - 球形导体：，均匀分布；腔体上电荷分布不一定均匀（只有球/柱对称时才均匀）。
  3. 用条件列方程： 逐区域求 ；等势条件给电势关系；接地条件给 或电荷守恒。

若外球壳接地：球壳电势为 0，而壳外的场只能由外表面电荷产生，故必须 外表面（外部场消失）。于是球壳的净电荷不再是原来的 ，而是 内表面外表面——多出来的电荷流进了大地。两球之间的电荷分布与场不受影响，所以 壳 不变，但 本身变了（因为零点变了）。

若内球接地：内球 ，内球上的电荷 变成未知量，要用 内球 反解 。这是"接地题"的标准打法：接地给的是电势条件（一个方程），电荷守恒给的是另一个方程。

保持清醒的两条：① 接地的导体，；它上面的总净电荷是"流动之后剩下的"，必须解出来，不能假设为 0。② 若导体孤立（不接地、不接电源），则它的总净电荷守恒，只能在内、外表面之间重新分配。

C3 静电屏蔽题

  • 腔内无电荷：腔内 ，且与外部场无关（外表面电荷分布会被外部场改变，但腔内不受影响）。
  • 腔内有电荷 ：腔内表面出现 ，腔外表面出现 ，外部场只由外表面电荷决定；壳接地则外部无场。

F2 毕奥-萨伐尔积分四步

  1. 取电流元 ，确定 （由电流元指向场点）。

  1. 由对称性判断 线形状，选与之重合的回路（圆/长方形）。

11 五条自检（每题算完 30 秒内过一遍）

  2. 极限：、、、、尺寸，看是否退化为你熟悉的结果。
