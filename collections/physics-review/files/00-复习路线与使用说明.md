## 1 三章主线：一条线串起来

```
第12章  真空中的电荷 → 场  ────────────────────────────┐
       电荷 ─→ 库仑定律 ─→ 场强叠加 ─→ 高斯定理(求对称场) │
                              └→ 环路定理 ─→ 电势 U ─→ E = −∇U
                                                        │
第13章  场中有物质 ─→ 导体（自由电荷重新分布，E内=0）     │
                    ─→ 电介质（极化，出现极化电荷）      │
       统一处理：D 的高斯定理 ∮D·dS = Σq₀  →  E = D/ε  →  U  →  C  →  W = ½CU²
                                                        │
第14章  电荷"流动"起来 ─→ 电流 I、电流密度 j、j = σE      │
       运动的电荷产生磁场 ─→ 毕奥-萨伐尔定律 / 安培环路定理
       磁场反过来作用于电流与运动电荷 ─→ 安培力、磁力矩、洛伦兹力
```

一句话总结三章的逻辑差别：

- **12 章：给电荷，求场和电势**（自由空间，没有边界）
- **13 章：给导体 / 介质，先问电荷怎么分布**（有边界，边界条件决定一切）
- **14 章：给电流，求磁场；给磁场，求力和力矩**（与 12 章完全平行的一整套）

## 2 建议的复习路线（按 6 小时估算，可按比例缩放）

### 第一轮：过公式 + 看懂例题（约 3 小时）
1. 打开 `01-公式速查表.md`，把每章公式**遮住右半边**自己默写一遍，默不出的做记号（30 分钟）。
2. 逐章读 `ch12` → `ch13` → `ch14`，重点看 **「0 本章地图」** 与 **「2 必须会推的结论」**（各 40 分钟）。
3. 例题先自己动笔试，卡壳超过 5 分钟再看解答，看完立刻把该题的**方法关键词**写在一张纸上（如"球对称→高斯定理→分段积分求 U"）。

### 第二轮：动手做题 + 归纳错因（约 2.5 小时）
1. 做各章末尾 **「5 本章自测」**，限时。
2. 做 `02-通用做题方法与题型套路.md` 里的**方法自检清单**，确认每种题型你都能在 1 分钟内说出"用哪个公式、为什么"。
3. 打开 `03-综合自测卷.md` 限时 60 分钟，做完对答案，把错题按下列四类打标签：
   - A 概念错（不知道物理图像）
   - B 公式错（记错形式或适用条件）
   - C 数学错（积分、矢量分解、单位换算）
   - D 审题错（漏条件、看错"接地/断开电源"）

### 考前 1 小时：只看三样东西（30 分钟）
1. `01-公式速查表.md`（尤其带 ★ 的高频式）
2. 各章 **「4 易错点清单」**
3. 自己那张"错因标签纸"

## 3 符号约定（全资料统一，避免与课本混淆）

| 量 | 符号 | 说明 |
| --- | --- | --- |
| 电荷量 | $q$、$Q$ | 点电荷用 $q$，带电器件总电荷用 $Q$ |
| 电荷线密度 / 面密度 / 体密度 | $\lambda$、$\sigma$、$\rho$ | 与电阻率 $\rho$ 同符号，第 14 章会显式注明"电阻率" |
| 电场强度 | $\boldsymbol{E}$、$E$ | 矢量粗斜体，分量标量斜体 |
| 电位移 | $\boldsymbol{D}$ | $\boldsymbol{D}=\varepsilon_0\varepsilon_r\boldsymbol{E}$ |
| 极化强度 | $\boldsymbol{P}$ | $\sigma'=\boldsymbol{P}\cdot\boldsymbol{e}_n$ |
| 电势 | $U$ | 课本有处用 $V$，本资料统一 $U$；$U_{AB}=U_A-U_B$ |
| 电势能 | $W$ | $W=qU$；静电能（电容器储能）用 $W_e$ |
| 电容 | $C$ | 单位 F |
| 相对介电常数 | $\varepsilon_r$ | 无量纲；$\varepsilon=\varepsilon_0\varepsilon_r$ |
| 电流 / 电流密度 | $I$、$\boldsymbol{j}$ | $I=\int\boldsymbol{j}\cdot\mathrm{d}\boldsymbol{S}$ |
| 电动势 | $\varepsilon$ | 与介电常数同符号，看上下文；本资料在 14 章写作 $\varepsilon_{\text{源}}$ 以免混淆 |
| 磁感应强度 | $\boldsymbol{B}$ | 单位 T |
| 磁通量 | $\Phi_m$ | 单位 Wb |
| 磁矩 | $\boldsymbol{m}$ | $\boldsymbol{m}=I\boldsymbol{S}=IS\boldsymbol{e}_n$ |
| 真空介电常数 / 磁导率 | $\varepsilon_0$、$\mu_0$ | 见下表 |
| 静电力常量 | $k$ | $k=1/(4\pi\varepsilon_0)$ |

**必须记牢的常量**

$$k=\frac{1}{4\pi\varepsilon_0}=8.99\times10^{9}\ \mathrm{N\cdot m^2/C^2}\approx 9\times10^{9},\quad
\varepsilon_0=8.85\times10^{-12}\ \mathrm{F/m}$$

$$\mu_0=4\pi\times10^{-7}\ \mathrm{H/m}\approx1.26\times10^{-6}\ \mathrm{H/m},\quad
e=1.60\times10^{-19}\ \mathrm{C},\quad m_e=9.11\times10^{-31}\ \mathrm{kg}$$

## 4 考场策略（小测专用）

1. **先扫一遍全部题**，30 秒内给每题标"会 / 需想 / 不会"。先做"会"的，务必全对。
2. **场强题永远先问对称性**：球对称 → 高斯定理；轴对称 → 高斯定理；面对称 → 高斯定理；**都不是 → 只能积分或叠加**。选错方法会浪费大量时间。
3. **凡求电势**，先判断是"由 $E$ 积分"还是"用电势叠加"。分段带电体（球壳、圆柱）的 $U$ 一定要**分段写**，把分界点的连续性当作自检。
4. **凡有导体或介质**，第一句写"由静电平衡 / 极化规律得……"，把电荷分布先定下来，题目一半就解完了。
5. **写答案必带单位与方向**。矢量题的最终答案用"大小 + 方向（与某轴夹角或沿某方向）"表述。
6. **数量级自检**：$E\sim10^{3}\sim10^{6}\ \mathrm{V/m}$、$B\sim10^{-3}\sim10^{0}\ \mathrm{T}$（实验室常见）、平行板 $C\sim10^{-12}\ \mathrm{F}$。若算出 $E\sim10^{20}$，一定错。
7. 时间分配建议（90 分钟卷）：选择填空 30 分钟、计算大题 50 分钟、检查 10 分钟。任何单题超过 12 分钟先跳过。

## 5 三个最容易丢的"流程分"

批改时老师看的往往不是最终数字，而是这几句话有没有出现：

- 高斯定理题：**"由……对称性，高斯面上各点 $E$ 大小相等、方向沿法向"** —— 没写这句等于没证明。
- 电势题：**"取无穷远为电势零点"**（或说明为何不能取）。
- 电容题：**"设极板带电 $Q$，则板间场强 $E=\dots$，电势差 $U=\dots$，故 $C=Q/U=\dots$"**。
- 安培环路题：**"取与磁场线同心的圆形回路，绕向与 $I$ 成右手螺旋"**。
- 安培力题：**先画受力图与 $\mathrm{d}\boldsymbol{l}$ 的方向**，再写叉乘。

把这些句子当成模板背下来，比多刷十道题有用。
