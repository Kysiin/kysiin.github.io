# 通用做题方法与题型套路（三章通用）

>这三章的题，90% 都能归到下面 8 个套路里。做不出来的题，通常是**第一步"识别题型"就错了**，而不是数学不会。
>建议：先读第 1 节的"暗示词 → 方法"对照表，再读具体套路，最后背第 9 节的格式模板。

---

## 1 题型识别：先看题目"给了什么、问了什么"

### 1.1 三步定位法

1. **看场源形状** → 决定用什么方法求场
   - 点电荷 / 几个点电荷 → 场强叠加（矢量），电势叠加（标量）
   - 规则形状连续带电体（棒、环、盘）→ **微元积分**（能积分就积分，不能积分考虑结论）
   - 球 / 柱 / 平面且"均匀带电" → **高斯定理**
   - 已有导体 → **先求电荷分布**（可能来自静电平衡、接地、感应）
2. **看有没有"物质"** → 是否出现导体、介质、$C$、$\varepsilon_r$、电荷重新分布
   - 有 → 走第 4、5、6 节（导体/电容/能量套路）
   - 没有 → 纯真空场问题，走第 2、3 节
3. **看问的是什么量** → 决定最终一步
   - 问 $E$ → 通常到"大小 + 方向"结束
   - 问 $U$、电势差 → 需要 $E(r)$ 的**分段**表达式再积分
   - 问做功、能量 → 能量式或 $qU_{AB}$

### 1.2 题目暗示词 → 方法对照表（考场最实用）

| 题目里出现 | 立刻想到 |
| --- | --- |
| "均匀带电""无穷长""无限大""球面对称" | 高斯定理 |
| "细棒""圆环""圆盘""一段圆弧""某点距端点" | 微元积分 + 对称性消元 |
| "导线""导体球""金属壳""静电平衡""接地" | 电荷重新分布（先画电荷！） |
| "空腔""腔内有电荷""屏蔽" | 内表面 $-q$，外表面 $Q+q$ |
| "充满介质""相对介电常数 $\varepsilon_r$""插入介质板" | $\boldsymbol{D}$ 的高斯定理 |
| "断开电源后""充电后移去电源" | **电荷 $Q$ 不变** |
| "接在电源上""保持电压不变" | **电压 $U$ 不变** |
| "平行板""极板间距变为原来的…" | 电容三式 + 能量三式 |
| "串/并联" | 电容串并联看 $Q$ 还是 $U$ 相同 |
| "电场力做功""电势能变化" | $W_{AB}=qU_{AB}$，注意符号 |

| "从静止加速后进入磁场""回旋""偏转半径" | 洛伦兹力圆周运动，先用 $qU=\frac12mv^2$ 求 $v$ |

## 2 套路 A：求电场强度

### A1 点电荷（少数几个）——矢量叠加
1. 画图，标出每个电荷到待求点的距离与方向。
2. 写出每个场强的**大小**：$E_i=\dfrac{1}{4\pi\varepsilon_0}\dfrac{q_i}{r_i^2}$。
3. **分解到坐标轴**（不要直接算矢量和），对称性会让某些分量自动抵消。
4. 合成：$E=\sqrt{E_x^2+E_y^2}$，方向 $\tan\theta=E_y/E_x$。

>常见陷阱：一维共线时把方向搞反。建议统一规定"向右为正"，负电荷的场强代入负号。

### A2 连续带电体——微元法（五步）
1. **取微元** $\mathrm{d}q=\lambda\mathrm{d}l$ 或 $\sigma\mathrm{d}S$ 或 $\rho\mathrm{d}V$。
2. 写微元在场点的**大小** $\mathrm{d}E=\dfrac{1}{4\pi\varepsilon_0}\dfrac{\mathrm{d}q}{r^2}$。
3. **利用对称性判断哪些分量抵消**（例：圆环轴线上垂直轴的分量全抵消；直棒中垂线上平行棒方向的分量抵消）。
4. 只对**保留下来的分量**积分，把积分变量统一成**一个**变量（常用角度或坐标 $x$），并写出**积分限**。
5. 得出结果后做**极限检验**：$x\to\infty$ 时是否退化为点电荷公式；$x\to0$ 时是否符合常识。

>记住三个"模板积分"：
>$$\int\frac{\mathrm{d}x}{\left(x^2+a^2\right)^{3/2}}=\frac{x}{a^2\sqrt{x^2+a^2}},\qquad
>\int_0^{2\pi}\mathrm{d}\theta=2\pi,\qquad
>\int\cos\theta\,\mathrm{d}\theta=\sin\theta$$
>圆环、圆盘、直棒三类题的积分本质都是第一条。

### A3 高对称——高斯定理（三步，缺一步就扣分）
1. **说明对称性**："由球（柱/面）对称性，高斯面上各点场强大小相等，方向沿法线方向。"
2. **选高斯面**：球对称→同心球面；轴对称→同轴圆柱面（含端面）；面对称→对称的长方体（两底面平行带电面）。
3. **写通量、代电荷**：$\oint\boldsymbol{E}\cdot\mathrm{d}\boldsymbol{S}=E\cdot S=\dfrac{q_{\text{内}}}{\varepsilon_0}$，解出 $E$。

$$E=\frac{q_{\text{内}}}{\varepsilon_0 S}\quad\Longrightarrow\quad
\begin{cases}\text{球面：}S=4\pi r^2\\[4pt]\text{圆柱侧面：}S=2\pi rl\quad(l\text{ 为柱高})\\[4pt]\text{平面：}S=2A\quad(A\text{ 为底面积})\end{cases}$$

>**判据**：如果高斯面上的 $E$ 不一定处处相等，就**不能**用高斯定理求 $E$（但通量仍可算）。这是最常见的误用。

### A4 叠加/补偿法（技巧题）
把"带孔的板""缺一角的环"看成"完整物体 + 负电荷物体"的叠加。如无限大带电平板上挖掉一个半径 $R$ 的圆盘：$\boldsymbol{E}=\boldsymbol{E}_{\text{全板}}-\boldsymbol{E}_{\text{圆盘}}$。

## 3 套路 B：求电势及相关量

### B1 两条路线，先选对

| 已知 | 路线 | 适用 |
| --- | --- | --- |
| 已知电荷分布，形状规则 | **电势叠加**：$U=\int\dfrac{\mathrm{d}q}{4\pi\varepsilon_0r}$ | 标量，最省力，尤其适合"多个点电荷/圆环/球壳" |
| 已知 $E(r)$ | $U_A=\int_A^{\text{参考点}}\boldsymbol{E}\cdot\mathrm{d}\boldsymbol{l}$ | 导体、分段带电体、电荷被重新分布后 |
| 已知 $U$，求 $E$ | $E_l=-\partial U/\partial l$ | 给电势函数的题 |

### B2 分段带电体求电势（最高频难点）
1. **先写出 $E(r)$ 的分段表达式**（球壳内 $E=0$，球体内 $E\propto r$……）。
2. **分区域讨论**：以球为例，求 $r<R$ 处电势时必须**从该点积到无穷远**，路径上会经过两种 $E$ 表达式，所以要分段积分：
$$U(r<R)=\int_r^R E_{\text{内}}\,\mathrm{d}r+\int_R^{\infty}E_{\text{外}}\,\mathrm{d}r$$
3. **自检**：在分界 $r=R$ 处，两段表达式必须给出相同值。若不等，说明漏了项。

>常用捷径：球壳内部 $U$ 处处相等，等于球壳表面电势 $\dfrac{Q}{4\pi\varepsilon_0R}$ —— 记住这条能省一半时间。

### B3 电势零点怎么取
- 有限带电体：取无穷远（简单）。
- **无限长直线、无限大平面**：不能取无穷远（积分发散），改取某处（如 $r=a$）为零，或用"电势差"表述。
- 导体接地：该导体 $U=0$，这本身就是条件，用来反解电荷。

### B4 电势差 / 做功 / 电势能
$$U_{AB}=\int_A^B\boldsymbol{E}\cdot\mathrm{d}\boldsymbol{l},\qquad W_{AB}=qU_{AB},\qquad W_p=qU$$
符号规则：**正电荷沿电场线方向移动，电场力做正功，电势能减少。**代入时保留 $q$ 的符号，就不容易错。

## 4 套路 C：导体静电平衡（电荷分布优先）

### C1 万能前三步
1. **判断静电平衡**：导体内部 $E=0$，整块导体等势 → 立刻能写出"某两个点电势相等"。
2. **分配电荷**：写出**每一个表面**的电荷（用 $q_{\text{内}}/Q/q$ 表示），再叠加求场。
   - 实心导体：电荷全在外表面。
   - 球形导体：$\sigma=\dfrac{Q}{4\pi R^2}$，均匀分布；腔体上电荷分布不一定均匀（只有球/柱对称时才均匀）。
3. **用条件列方程**：$\oint\boldsymbol{E}\cdot\mathrm{d}\boldsymbol{S}=q/\varepsilon_0$ 逐区域求 $E$；等势条件给电势关系；接地条件给 $U$ 或电荷守恒。

### C2 同心球壳标准题（必会）
设内球半径 $R_1$ 带 $q$，外球壳内半径 $R_2$、外半径 $R_3$ 带 $Q$：
- 内球表面：$q$；球壳内表面：$-q$；球壳外表面：$Q+q$。
- 场强：$r<R_1$ 为 0；$R_1<r<R_2$ 为 $\dfrac{q}{4\pi\varepsilon_0r^2}$；$R_2<r<R_3$ 为 0（导体内）；$r>R_3$ 为 $\dfrac{q+Q}{4\pi\varepsilon_0r^2}$。
- 电势：$R_2\le r\le R_3$ 区间等势，其值等于 $\int_{R_3}^\infty E\mathrm{d}r=\dfrac{q+Q}{4\pi\varepsilon_0R_3}$。

**若外球壳接地**：球壳电势为 0，而壳外的场只能由外表面电荷产生，故必须 $q_{\text{外表面}}=0$（外部场消失）。于是球壳的**净**电荷不再是原来的 $Q$，而是 $q_{\text{内表面}}+q_{\text{外表面}}=-q$——多出来的电荷流进了大地。两球之间的电荷分布与场**不受影响**，所以 $U_1-U_{\text{壳}}$ 不变，但 $U_1$ 本身变了（因为零点变了）。

**若内球接地**：内球 $U=0$，内球上的电荷 $q'$ 变成未知量，要用
$$U_{\text{内球}}=\frac{q'}{4\pi\varepsilon_0}\left(\frac{1}{R_1}-\frac{1}{R_2}\right)+\frac{q'+Q}{4\pi\varepsilon_0R_3}=0$$
反解 $q'$。这是"接地题"的标准打法：**接地给的是电势条件（一个方程），电荷守恒给的是另一个方程**。

>保持清醒的两条：① **接地的导体，$U=0$；它上面的总净电荷是"流动之后剩下的"，必须解出来，不能假设为 0。**② 若导体**孤立**（不接地、不接电源），则它的**总净电荷守恒**，只能在内、外表面之间重新分配。

### C3 静电屏蔽题
- 腔内无电荷：腔内 $E=0$，且与外部场无关（外表面电荷分布会被外部场改变，但腔内不受影响）。
- 腔内有电荷 $q$：腔内表面出现 $-q$，腔外表面出现 $Q+q$，**外部场只由外表面电荷决定**；壳接地则外部无场。

## 5 套路 D：含介质的场与电容（$\boldsymbol{D}\to E\to U\to C$）

### D1 四步链（本章最重要的一条流程）
$$\boldsymbol{D}\xrightarrow{\ \text{自由电荷高斯定理}\ }\to\boldsymbol{E}=\frac{\boldsymbol{D}}{\varepsilon_0\varepsilon_r}\to U=\int\boldsymbol{E}\cdot\mathrm{d}\boldsymbol{l}\to C=\frac{Q}{U}$$

- 第一步只看**自由电荷**（导板上的电荷、给定的 $\lambda$、$q$）。
- 介质内部的极化电荷**不进入** $\boldsymbol{D}$ 的高斯定理，但会影响 $\boldsymbol{E}$（已由 $\varepsilon_r$ 体现）。
- 求不同区域的场：分别对每个区域的介质用 $\varepsilon_{r1}$、$\varepsilon_{r2}$。

### D2 平行板插介质板的两种插入方式
- 介质板**平行**于极板（相当于两个电容器**串联**，若中间夹着真空层）或用"$E$ 在不同层不同、$D$ 相同"。
- 介质板**垂直**于极板（相当于两个电容器**并联**，两部分的 $U$ 相同、$D$ 不同）。
- 判断口诀：**"场强同向串联、电势同高并联"**——先问哪一部分的 $E$ 相同、哪一部分的 $U$ 相同，再决定怎么等效。

### D3 电容三式 + 组合
求等效电容先把电路画成串并联结构；串并联时牢记：

- 串联：$Q$ 相同、$U$ 相加、$\frac{1}{C}=\sum\frac{1}{C_i}$、总耐压等于各耐压之和。
- 并联：$U$ 相同、$Q$ 相加、$C=\sum C_i$。

## 6 套路 E：电容器的"两种约束"（最高频易错）

| 情况 | 不变的量 | 随之变化 |
| --- | --- | --- |
| **断开电源**后插入介质 / 改变间距 | $Q$ 不变 | $C$ 变 → $U=Q/C$ 变 → $E=U/d$ 或 $D$ 分析 → $W=Q^2/(2C)$ 变 |
| **接通电源**时插入介质 / 改变间距 | $U$ 不变 | $C$ 变 → $Q=CU$ 变 → $W=\frac12CU^2$ 变 |

处理模板：
1. 第一句写明"由题意，电源断开，故极板电荷 $Q$ 保持不变（或电压 $U$ 不变）"。
2. 用 $C$ 的几何式算变化后的 $C'$。
3. 由约束量推出另一个量，再算 $E$、$W$。
4. 若问"外力做功"，用能量守恒：$A_{\text{外}}=\Delta W_e-\text{（电源做功）}$。电源做功 $A_{\text{源}}=\varepsilon_{\text{源}}\Delta Q$，符号别丢。

## 7 套路 F：求磁场（与静电场的"镜像式"平行）

### F1 两条路线

| 载流体 | 方法 |
| --- | --- |
| 有限长直导线、圆环、圆弧、组合导线、任意形状 | **毕奥-萨伐尔定律积分** |
| 无限长直导线、无限长螺线管、螺绕环、同轴电缆、圆柱导体 | **安培环路定理** |

### F2 毕奥-萨伐尔积分四步
1. 取电流元 $I\mathrm{d}\boldsymbol{l}$，确定 $\boldsymbol{e}_r$（**由电流元指向场点**）。
2. 判断 $\mathrm{d}\boldsymbol{l}\times\boldsymbol{e}_r$ 的**方向**（右手螺旋），题目要求合成时先定方向再定大小。
3. 写大小 $\mathrm{d}B=\dfrac{\mu_0}{4\pi}\dfrac{I\mathrm{d}l\sin\theta}{r^2}$，把所有变量统一（角度或坐标），写**积分限**。
4. 多段导线：分别算完再**矢量相加**（同向加、反向减）。

>三句口诀：**直导线看角度、圆环看距离、圆弧看圆心角。**

### F3 安培环路定理三步
1. 由对称性判断 $B$ 线形状，选与之重合的回路（圆/长方形）。
2. 说明"回路上 $B$ 处处大小相等、方向沿回路切向"，于是 $\oint\boldsymbol{B}\cdot\mathrm{d}\boldsymbol{l}=B\cdot2\pi r$（或 $B\cdot l$）。
3. 算 $\sum I_{\text{内}}$：**电流方向与回路绕向成右手螺旋取正，反之取负**；回路外的电流一律不计入。

### F4 组合例题的分解技巧
"直导线 + 半圆弧 + 直导线"这类题：
- 逐段算 $B$，用 "$B$ 指向纸内 / 纸外" 标注方向；
- 取纸外为正，纸内为负，代数和；
- 直导线的 $B$ 用"距导线距离"，圆弧的 $B$ 用圆心角，别混。

## 8 套路 G：磁力、磁力矩、带电粒子

1. **安培力**：$\mathrm{d}\boldsymbol{F}=I\mathrm{d}\boldsymbol{l}\times\boldsymbol{B}$；一段直导线在匀强场中 $\boldsymbol{F}=I\boldsymbol{L}\times\boldsymbol{B}$（$\boldsymbol{L}$ 为**起点指向终点**的有向线段）；任意弯曲导线在匀强场中受力也只依赖首尾连线。
2. **两根平行长直导线**：单位长度受力 $\dfrac{\mu_0I_1I_2}{2\pi d}$，**同向相吸、反向相斥**。
3. **线圈**：$\boldsymbol{m}=I\boldsymbol{S}$（$\boldsymbol{e}_n$ 与电流成右手螺旋），$\boldsymbol{M}=\boldsymbol{m}\times\boldsymbol{B}$，最大 $M=ISB$（$S\parallel B$ 时 $M=0$）。转动做功 $A=I\Delta\Phi$（与磁通量有关，若已学）。
4. **带电粒子**：
   - 先求速度：常用 $qU=\frac12mv^2$ 或 $\frac12mv^2=qU$。
   - 圆周运动：$R=\dfrac{mv}{qB}$、$T=\dfrac{2\pi m}{qB}$，**周期与速率无关**。
   - 若 $v$ 与 $B$ 不垂直：分解为平行（匀速直线）与垂直（圆周）→ 螺旋线。
   - 电场 + 磁场同时存在：平衡时 $v=E/B$；否则两力分别写出再求合力。

## 9 好答案长什么样（格式模板）

小测评分往往看"过程链条"，把下列句子写出来，等于拿到大部分过程分：

**求场强（高斯定理型）**
>由球对称性，取半径为 $r$ 的同心球面为高斯面，面上各点 $\boldsymbol{E}$ 大小相等、方向沿径向。由高斯定理 $\oint\boldsymbol{E}\cdot\mathrm{d}\boldsymbol{S}=4\pi r^2E=\dfrac{q_{\text{内}}}{\varepsilon_0}$，得……（分 $r<R$、$r>R$ 讨论）

**求电势**
>取无穷远为电势零点。由 $U=\int_P^\infty\boldsymbol{E}\cdot\mathrm{d}\boldsymbol{l}$，当 $r<R$ 时路径经过两个区域，$U(r)=\int_r^{R}E_1\mathrm{d}r+\int_R^{\infty}E_2\mathrm{d}r=\dots$

**求电容**
>设极板带电荷 $\pm Q$，板间场强 $E=Q/(\varepsilon_0\varepsilon_rS)$，两板电势差 $U=Ed=\dfrac{Qd}{\varepsilon_0\varepsilon_rS}$，故 $C=\dfrac{Q}{U}=\dfrac{\varepsilon_0\varepsilon_rS}{d}$。

**求磁场（安培环路）**
>由轴对称性，取以导线为轴、半径 $r$ 的圆形回路，绕向与电流成右手螺旋；回路上 $\boldsymbol{B}$ 沿切向、大小相等，$\oint\boldsymbol{B}\cdot\mathrm{d}\boldsymbol{l}=2\pi rB=\mu_0 I$，得 $B=\dfrac{\mu_0I}{2\pi r}$，方向由右手螺旋决定。

**求安培力**
>取电流元 $I\mathrm{d}\boldsymbol{l}$，所受安培力 $\mathrm{d}\boldsymbol{F}=I\mathrm{d}\boldsymbol{l}\times\boldsymbol{B}$，方向为……（画出）；整段导线合力 $F=\int\mathrm{d}F=\dots$，方向……

| --- | --- |
| 常用积分 | $\displaystyle\int\frac{\mathrm{d}x}{\left(x^2+a^2\right)^{3/2}}=\frac{x}{a^2\sqrt{x^2+a^2}}$；$\displaystyle\int\frac{\mathrm{d}x}{x^2+a^2}=\frac{1}{a}\arctan\frac{x}{a}$；$\displaystyle\int\frac{\mathrm{d}x}{x}=-\ln\lvert x\rvert$ |
| 圆弧长与角度 | $l=R\theta$（$\theta$ 弧度）；$\displaystyle\int_0^{\pi}\sin\theta\,\mathrm{d}\theta=2$ |
| 面元 | 圆盘 $\mathrm{d}S=2\pi r\mathrm{d}r$（取环带）；球面 $\mathrm{d}S=4\pi R^2$（对称时） |
| 矢量分解 | $E_x=E\cos\theta$，$E_y=E\sin\theta$；$\tan\theta=\dfrac{E_y}{E_x}$ |
| 叉乘判断 | 右手螺旋：四指由第一矢量转向第二矢量，拇指为结果方向；或行列式 $\boldsymbol{a}\times\boldsymbol{b}=\begin{vmatrix}\boldsymbol{i}&\boldsymbol{j}&\boldsymbol{k}\\a_x&a_y&a_z\\b_x&b_y&b_z\end{vmatrix}$ |
| 散度/旋度（选） | $\nabla\cdot\boldsymbol{E}=\rho/\varepsilon_0$；$\nabla\times\boldsymbol{E}=0$ $\Rightarrow$ $\boldsymbol{E}=-\nabla U$ |

## 11 五条自检（每题算完 30 秒内过一遍）

1. **量纲**：$E$ 是 $\mathrm{V/m}$ 或 $\mathrm{N/C}$；$B$ 是 T；$C$ 是 F；$W$ 是 J。指数写错（如漏了 $\varepsilon_0$）会在量纲上暴露。
2. **极限**：$x\to0$、$x\to\infty$、$R\to0$、$\theta\to0$、$d\gg$尺寸，看是否退化为你熟悉的结果。
3. **连续性**：分段表达式在分界处必须连续（$r=R$ 时 $E$ 可以跳变，$U$ 必须连续）。
4. **符号**：电势高低、做功正负、电流方向、力的方向是否符合物理直觉。
5. **方向**：矢量题是否给了方向？否则至少减一半分。

## 12 常见"卡壳"及脱困办法

| 卡在哪 | 换什么打法 |
| --- | --- |
| 积分积不出来 | 换成角度变量 $\theta$；或先算"对称分量"；或改用已知结论 + 叠加 |
| 不知道电荷在哪 | 先假设电荷，用"内部 $E=0$"或"它是等势体"列方程 |
| 分段太多、混乱 | 画一张 $r$ 轴，把每个区域里的 $\varepsilon_r$、$q_{\text{内}}$、$E(r)$ 写在下面 |
| 电势算出来分界处不连续 | 99% 是积分路径漏了某一段 |
| 磁场方向总是搞反 | 一律先画平面图（纸面为截面），把 $\boldsymbol{B}$ 标成"⊙ 向外 / ⊗ 向里" |
| 电容器变化题乱 | 先写一句话："电源断开 $\Rightarrow$ $Q$ 不变"（或"接电源 $\Rightarrow$ $U$ 不变"） |
| 时间不够 | 放弃最后那道"组合导线 + 求某点 $\boldsymbol{B}$"的题，回去检查前面的填空 |
