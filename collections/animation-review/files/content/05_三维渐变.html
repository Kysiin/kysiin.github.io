5.1 三维 Morphing 的一般框架与难点

目标：给定两个三维模型 M₀、M₁，生成中间形状 M(t)，t∈[0,1]，且 M(0)=M₀、M(1)=M₁，中间过程自然（无自交、特征保持、体积合理）。

通用流程：预处理（归一化、对齐/配准）→ 建立对应（correspondence）→ 插值（顶点或场）→ 重建/提取曲面 → 渲染。

为什么难：

难点 说明
拓扑不同 顶点数、连接关系可能完全不同（一个有一个孔，一个没有），无法直接顶点对应
大变形/大旋转 两个模型姿态差异大，直线插值会"塌陷/穿插"
语义对应 要"手对手、头对头"，几何最近点未必是语义对应点
特征保持 尖角、边缘、细节在插值中容易丢失或变圆
自交与体积 中间形状可能自交、体积剧烈变化
效率 高分辨率模型与 RBF 求解开销大

对应方法：同拓扑→顶点直接对应；不同拓扑→球面/柱面参数化（星形、Genus-0 模型）、隐式/体表示、非刚性配准（ARAP/最优传输）、特征点手工标注。

5.2 基于星形物体的多面体 Morphing

星形物体（star-shaped polyhedron）的定义：存在一点 O（称为核，kernel），使得从 O 出发到表面上任意点的射线与表面只有一个交点（O 能"看见"整个表面）。等价地：表面可写成以 O 为中心的径向函数 r = r(θ, φ)。

方法步骤：

  1. 对每个星形多面体选取核点 O₀、O₁；
  2. 用球面投影建立参数化：把单位球面上的每个方向 d 映射到表面点 p = O + r(d)·d，得到径向函数 r₀(d)、r₁(d)（凹处/多值处需处理，星形条件下单值）；
  3. 在共同的球面网格（经纬网格或细分二十面体）上采样，形成顶点一一对应；
  4. 插值： （可同时插值方向 d，以适应相对旋转；也可把球面网格的顶点方向一起插值/旋转对齐）
  5. 用插值后的顶点重建网格（拓扑沿用球面网格），得到中间形状。

优点： - 不需要两个模型拓扑一致（通过共同球面网格建立对应），可处理顶点数不同的模型； - 计算简单、稳定、易实现，中间形状光滑； - 径向插值天然"沿半径伸缩"，不会像顶点直线插值那样塌陷。

缺点： - 只适用于星形（近似凸）物体：有凹陷、孔洞、多连通、遮挡的模型不满足"核可见"条件； - 球面参数化在极点附近有畸变/奇异，方向采样不均会导致扭曲； - 半径线性插值可能过零或导致自交/翻折（需正性约束）； - 若两模型相对旋转没有对齐，中间会出现"拧麻花"式的扭曲； - 难以保持尖锐特征与细节。

5.3 基于体表示的三维 Morphing（volumetric / 距离场方法）

表示：把模型嵌入一个体素网格，用标量场表示形状——有符号距离场（SDF）、占据率（occupancy）或密度场 f(x)。

方法步骤：

  1. 体素化：对 M₀、M₁ 分别计算体数据 f₀(x)、f₁(x)（表面处 f=0，内部为负，外部为正）；
  2. 场插值：
  3. 提取等值面：对每个 t 用 Marching Cubes（或对偶轮廓/Dual Contouring）提取 f(x,t)=0 的曲面，得到中间网格；
  4. 可对中间结果做平滑/重网格化/特征恢复。

优点： - 自然处理拓扑变化：合并、分裂、穿孔、断开都自动发生（等值面拓扑可以改变）； - 完全不需要点/面/网格的对应，两个模型可以毫无关系； - 稳健：对噪声、非流形、多边形质量差不敏感； - 适合任意形状（凹形、多连通、带孔），是"通用"方案。

缺点： - 分辨率决定精度：细节（薄片、尖角、小孔）会丢失或被"糊"掉，内存与计算随分辨率立方增长； - 线性插值 SDF 会导致体积/表面偏移（中间形状整体膨胀或收缩），需用距离场重初始化、归一化或"体积保持"的插值； - 需要后处理（平滑、重网格、特征恢复），表面可能出现块状/阶梯伪影； - 难以保持纹理坐标与尖锐特征； - 计算量大（体素化 + 每帧 Marching Cubes），不利于交互。

约束与求解：给一组约束点——表面点 f=0、内部点 f=−1、外部点 f=+1，解线性方程组求 w_i（与多项式系数）。因为薄板样条是"最小弯曲能量"的解，所以曲面平滑且能"自然外推"到稀疏约束之间。

Morph 的做法：

  1. 分别对两个模型建立隐函数 f₀、f₁（各自选取表面/内部/外部约束点）；
  2. 插值隐函数：
  3. 对每个 t 用 Marching Cubes 提取 f=0 等值面，得到中间形状；
  4. 可通过"约束点对应"（把两模型的约束点配对/对齐，甚至把两套约束点合并求解）来控制 morph 过程，使特征"对着变"。

优点： - 隐式表示天然平滑，中间结果光滑、无接缝； - 自动处理拓扑变化（两个曲面可合并、分裂、包络），无需网格对应； - 不需两模型拓扑一致，只需约束点； - 可用约束点控制对应关系（可控性强）； - 插值后仍是"最小能量曲面"，形状合理。

缺点： - 求解 RBF 线性系统 O(N³)，N 稍大就非常慢、内存占用高（改进：紧支撑 RBF、快速多极、分区求解）； - 约束点的选取（数量、内外分布）影响结果，可能产生多余"鼓包"、体积膨胀或细节丢失； - 中间形状的体积/体积变化不受控； - 需要体素化 + Marching Cubes，仍受体素分辨率限制，尖锐特征难保持； - 对高度非凸/薄壁结构，隐式化可能"填平"细节。

5.5 三种三维 Morphing 方法对比

维度 星形物体多面体 morphing 体表示（SDF/占据） 变分隐式曲面（RBF）
对应方式 共同球面参数化（径向函数） 无需对应（体素网格） 约束点（隐式）
拓扑变化 不能（固定球面网格拓扑） 可以 可以
适用形状 仅星形/近似凸 任意 任意（但薄壁差）
精度/细节 中（受球面采样） 低~中（受体素分辨率） 中（受约束点与 RBF）
计算效率 高（快） 中（体素化 + MC 较慢） 低（O(N³) 解方程）
主要缺陷 形状限制、极点畸变、可能自交 分辨率、体积偏移、块状伪影 速度慢、需选点、体积不可控
典型场景 凸体/简单模型、快速预览 通用、拓扑变化、医学/仿真 高质量平滑过渡、可控对应

5.6 补充：其他三维 Morphing 思路（了解即可）

  • 同拓扑顶点插值：直接对顶点做 (1−t)p₀+tp₁，简单但会塌陷/穿插；改进用内在量（边长+二面角）或拉普拉斯坐标 + 局部旋转（保细节 morphing）；
  • 基于非刚性配准：先做 ARAP/最优传输配准把 M₁ 变形到 M₀ 的对应，再插值位移场；
  • 基于点云/神经表示：用 MLP 隐式场（NeRF/SDF）+ 插值网络参数或特征，属于数据驱动方法。
