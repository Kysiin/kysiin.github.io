## Q1 传统动画的 12 条基本原则及其原理（为什么要这样）

**答题骨架**：

1. **总述**：12 条由迪士尼九老在《The Illusion of Life》总结，服务于**可读性、可信性（重量）、表现力**；原为二维手绘，现已推广到三维。
2. **逐条列名 + 一句话含义**（写全 12 条名称就已拿到一半分）：
   - 挤压拉伸（表现重量/弹性，近似体积守恒）
   - 预期（动作前的反向蓄力，建立期待）
   - 舞台化（构图/剪影让观众一眼看懂）
   - 连贯动作法与关键动作法（两种制作方式）
   - 跟随动作与重叠动作（惯性 + 错峰）
   - 慢入慢出（起止慢、惯性）
   - 弧线（自然运动沿曲线）
   - 次要动作（补充主表演）
   - 时间/节奏（帧间隔决定重量与情绪）
   - 夸张（强化本质）
   - 扎实的描绘（结构/体积/重心）
   - 吸引力（魅力与可读性）
3. **原理归纳**：物理（惯性、重力、弹性）、知觉（可读性、期待）、表演（情绪、节奏）。
4. **三维中的变化**：部分原则由物理模拟自动满足（挤压拉伸、跟随动作、布料）；"扎实的描绘"转化为造型与解剖；关键动作法 + 曲线插值成为主流。

**加分点**：举一个具体例子（小球弹跳同时体现挤压拉伸、慢入慢出、弧线、跟随动作）。

## Q2 物体朝向的表示方式、万向节死锁、旋转矩阵转四元数、Slerp

**答题骨架**：

1. **五种表示**：旋转矩阵（9 参数、唯一、不可直接插值）、定角（绕固定轴，X-Y-Z）、欧拉角（绕自身轴）、轴线角（轴 + 角）、四元数（4 参数、无死锁）。
2. **定角与欧拉角的关系**：定角 X-Y-Z ≡ 欧拉角 Z-Y-X（矩阵相乘顺序与旋转顺序相反）。
3. **万向节死锁**：三参数参数化的**内在缺陷**；当第二个角使第一、三轴共线（如 β=±90°）时丢失一个自由度；表现为插值跳变、某些朝向不可达；因 SO(3) 非平直空间，**任何三参数方法都无法避免**。
4. **解决办法**：四元数 + Slerp、限制中间角、换顺序、矩阵累计。
5. **矩阵→四元数**：w = ½√(1+m00+m11+m22)，x=(m21−m12)/(4w)，y=(m02−m20)/(4w)，z=(m10−m01)/(4w)；w≈0 时用 Shepperd 分支（选最大对角元）。
6. **四元数表示**：q = (cos(θ/2), sin(θ/2)·u)，q 与 −q 等价；共轭为逆。
7. **Slerp**：θ = arccos(q₀·q₁)；Slerp = sin((1−t)θ)/sinθ·q₀ + sin(tθ)/sinθ·q₁；点积为负时取反走最短路径；匀速、大圆弧。

**加分点**：对比 nlerp；说明四元数复合只需 16 次乘法。

## Q3 2D Shape Blending 的两个子问题、内在形状插值与 Edge Tweaking

**答题骨架**：

1. **两个子问题**：①对应（correspondence：顶点/特征如何配对，顶点数不同需加密）；②插值路径（vertex path：中间形状走什么路径）。
2. **为什么路径是独立问题**：顶点线性插值在旋转时会"塌陷/缩小"，两条边同时向内插值导致边长变短。
3. **内在形状插值**：用边长 {l_i} 与转角 {θ_i}（绝对方向角 φ_i）描述形状；线性插值 l、φ（角度先 unwrap）；由 p_k = p_0 + Σ l_i e^{iφ_i} 重建；闭合约束 Σ l_i e^{iφ_i} = 0（2 个约束 vs 2n 个参数 → 有多余自由度，需均摊/最小二乘/优化处理）。
4. **优点**：不塌陷、旋转自然；**缺点**：需对应与加密、可能自交、闭合处理复杂。
5. **Edge Tweaking**：利用内在表示的多余自由度，对边（长度/方向）施加 δ(t) 的调整，要求 δ(0)=δ(1)=0（不改变两端形状），用来避免自交、改善中间形状。

**加分点**：写出复数形式的重建公式；指出"零空间编辑"这一思想。

## Q4 图像 Morphing 的原理与三类方法、StyleGAN 分层语义

**答题骨架**：

1. **两步原理**：warping（几何对齐）+ cross-dissolve（颜色混合）；公式 I(x,t) = (1−t)I₀(W₀⁻¹(x)) + tI₁(W₁⁻¹(x))；用反向映射避免空洞。
2. **基于网格**：对应三角形 → 每个三角形一个仿射变换 → 中间顶点线性插值 → 逆映射采样 → 混合；优点精确局部，缺点需一致三角化、大变形翻转。
3. **基于线对（Beier–Neely）**：有向线段对定义对应；权重 w_i = (l_i^p/(a+dist))^b；位移加权平均；优点交互简单，缺点大旋转折叠、参数难调。
4. **StyleGAN**：生成器 + 映射网络（z→w）+ 逐层 AdaIN；反演得 w₀,w₁；隐空间插值 w(t)（可分层不同 t）→ 生成；优点无需对应、质量高，缺点反演误差、解耦不完全、依赖数据。
5. **分层语义**：coarse（4²~8²）=姿态/脸型/性别/发型大形；middle（16²~32²）=五官/表情/发型细节；fine（64²~1024²）=颜色/纹理/肤色/细节。

**加分点**：说明"为什么可以在不同层用不同的 t"——因为不同层控制不同语义尺度。

## Q5 粒子系统、元球、群组动画（Boids / 社会力 / RVO / Continuum）

**答题骨架**：

1. **粒子系统原理**：大量简单粒子 + 随机生成 + 属性演化 + 生命周期；属性（位置/速度/寿命/颜色/大小）；流程（生成→更新→消亡→绘制）；可生成烟、火、水、雨雪、爆炸、沙尘、毛发等。
2. **元球融合**：每个元球一个势场 f_i(r)（如 (1−r²)³ 或 Wyvill 六次），总场 F=Σf_i，等值面 F=T 即表面；靠近时场叠加 → 等值面平滑连接；负元球可挖洞。
3. **粒子碰撞**：检测（面/三角形、空间哈希、CCD）+ 响应（法向反弹 × 恢复系数、切向摩擦、位置修正、粘附/消亡）。
4. **为什么需要群组动画**：规模大无法手工关键帧；需要涌现行为、可交互、可控、可信。
5. **Flocking 三层次**：Action Selection（策略/目标/规划）→ Steering（路径/转向力）→ Locomotion（关节动画）。
6. **Boids 三原则**：分离、对齐、聚集；局部规则涌现全局行为。
7. **导航行为**：追逐（预测目标未来位置）、躲避（预测后反向逃）、避障（检测盒 + 侧向力）、路径跟随（找路径上最近/前方点）、流场跟随（采样场向量作期望速度）、领导跟随（身后偏移点 + 避让 + 分离）。
8. **社会力**：驱动力 + 指数衰减的个体排斥 + 接触力/摩擦 + 随机项；能复现车道形成、拱形堵塞、faster-is-slower。
9. **RVO**：VO 锥 + 各让一半（顶点移到相对位置中点），选最接近期望速度的解；分布、对称、无振荡；局部最优。
10. **Continuum Crowds**：密度场 + eikonal 势场（快速行进）+ 速度场（−∇φ）+ 连续性方程推进；计算量与人数无关，但丢失个体细节。

**加分点**：给出方法与适用规模的对比（个体法 vs 连续法 vs 混合）。

## Q6 正向/逆向运动学、雅可比、CCD、FABRIK、FK vs IK

**答题骨架**：

1. **FK**：x = f(q) = T_root Π T_i(q_i)；唯一、快、无奇异，但控制末端困难。
2. **IK**：已知 x_d 求 q，使 f(q)=x_d；难点：非线性、多解、冗余、无解、奇异、限位。
3. **逆雅可比**：J = ∂f/∂q；Δq = J⁺Δx（伪逆）；奇异时用阻尼最小二乘 Δq = Jᵀ(JJᵀ+λ²I)⁻¹Δx；零空间做次级目标。
4. **CCD**：从末端向根，逐关节把"末端向量"旋到"目标向量"（轴 = u×v，角 = arccos）；简单、无需雅可比，但结果不自然。
5. **FABRIK**：位置法，判断可达性 → 后向（末端到目标，保持骨长）→ 前向（根回位，保持骨长）→ 迭代；快、稳定，但不保证限位/朝向。
6. **优化法**：min ‖f(q)−x_d‖² + λ‖q−q₀‖² + 限位/避障项，SQP/LM 求解；多目标但慢。
7. **FK vs IK 对比表**：解的存在性、计算、奇异、控制直观性、约束、自然性、用途。
8. **关节空间 vs 笛卡尔空间**：关节空间无奇异、便于插值；笛卡尔空间直观、易约束；两者用 IK 桥接。

**加分点**：说明"FK 负责表演、IK 负责约束"的工程实践。

## Q7 运动捕获的优缺点、顶点混合、运动重定向的挑战

**答题骨架**：

1. **动捕原理**：演员表演 → 传感设备记录 → 映射到骨架（光学/惯性/机械）。
2. **优点**：真实细腻、效率高、数据可复用、表演可控、复杂动作可行。
3. **缺点**：设备贵、遮挡/噪声需清理、重定向难、受演员能力限制、风格受限、不易编辑。
4. **绑定与顶点混合**：绑定姿态 M_i^bind、当前 M_i^cur；v' = Σ w_i (M_i^cur (M_i^bind)⁻¹) v，Σw_i=1；权重来源（手工/热扩散）；线性混合的 candy-wrapper 与体积损失，DQS 改进。
5. **重定向**：骨骼对应 → 角度映射 → 根节点按比例缩放 → 末端 IK 修正 → 后处理。
6. **带几何模型的重定向挑战**：比例差异（脚滑/穿地）、接触保持、自碰撞、环境/道具交互、重心平衡、关节限位、风格自然性、蒙皮质量。

**加分点**：写出顶点混合的完整数学表达（这是唯一要求"数学表示"的题）。

## Q8 Deformation vs Morphing、FFD、Cage 与 Laplacian

**答题骨架**：

1. **区别**：单个物体 vs 两个物体；不需要/需要对应；拓扑不变/可能变；v'=D(v) vs v(t)=插值。
2. **与表示无关的变形**：D: R³→R³，只依赖位置，与表示无关；优点通用、保连续、可组合；缺点不理解结构、大变形失真。
3. **Tapering/Twisting/Bending 公式**（各写一个）。
4. **FFD**：控制晶格 + 三变量 Bernstein：X'(s,t,u) = ΣΣΣ B_i^l(s)B_j^m(t)B_k^n(u)P'_{ijk}；步骤（构造晶格→逆映射求 (s,t,u)→移动控制点→求值）；优点与表示无关、光滑、可组合；缺点全局影响、需逆映射、大变形自交。
5. **EFFD**：任意形状/复合/细分晶格，提升局部控制。
6. **Cage**：p = Σφ_i c_i，Σφ_i=1；齐次形式 P̂ = Σφ_i Ĉ_i；MVC 权重公式；Green 坐标加法向项 p' = Σφ_i c'_i + Σψ_j s_j n'_j，保形。
7. **Laplacian**：δ_i = v_i − 平均邻居；min ‖LV'−Tδ‖² + λΣ‖v'_k−c_k‖²；加局部旋转（ARAP）；保细节。

**加分点**：指出"零空间/多余自由度"在 Edge Tweaking、Cage、Laplacian 中的共同作用。

## Q9 布料动画与隐式曲面（含 Muraki、Wyvill）

**答题骨架**：

1. **四种力**：拉伸、压缩、剪切、弯曲；压缩失稳 → 褶皱。
2. **Provot 模型**：质点-弹簧（结构/剪切/弯曲弹簧）；胡克力 + 阻尼 + 重力；显式积分；**应变限制**：超长则把端点沿连线移回 (1+ε)l₀。
3. **大步长隐式**：隐式欧拉 (M + hC + h²K)v^{n+1} = Mvⁿ + h(Fⁿ + Cvⁿ)（化为一组稀疏对称正定的线性方程）；稀疏对称系统（CG/Cholesky）；无条件稳定但过阻尼；自适应步长（误差、CFL/应变、碰撞事件）。
4. **隐式曲面优缺点**：紧凑、光滑、易融合/布尔、拓扑自动、内外判定易；但难控形状、需多边形化、纹理难、局部影响全局、尖角难。
5. **Muraki 三能量**：位置能量（曲面过数据点）、法向能量（法向一致）、收缩能量（防膨胀、紧凑）。
6. **Wyvill 六次多项式**：f(r) = 1 − (22/9)(r/R)² + (17/9)(r/R)⁴ − (4/9)(r/R)⁶（r≤R）；f(0)=1、f(R)=0、f′(R)=0、有限支撑；曲线平滑下降的钟形。

**加分点**：画出 Wyvill 曲线；解释为什么边界导数为 0（平滑融合）。

## Q10 碰撞处理三问题、包围体、k-DOP、SAT 与求交算法

**答题骨架**：

1. **三个问题**：检测、确认（接触点/法向/穿透深度）、响应。
2. **包围体选择**：紧致性、测试速度、更新速度、内存；球/AABB/OBB/k-DOP/凸包对比；层次化组合。
3. **k-DOP**：k/2 对固定方向平面，k 个标量；6=AABB、14、18、26；k 越大越紧；
4. **SAT**：凸体不相交 ⟺ 存在分离轴；候选轴 = 面法向 + 棱叉积（OBB 15 轴）；给出 MTD。
5. **构建**：AABB（min/max）；k-DOP（逐方向投影取 min/max）。
6. **四类求交**：
   - 射线/平板层：t₁,t₂ 更新 [t_near, t_far]，判 t_near ≤ t_far；
   - 射线/三角形：Möller–Trumbore（det、u、v、t）；
   - AABB/AABB：3 轴区间重叠；
   - k-DOP/k-DOP：k/2 个方向区间重叠，早退出。
7. **重要规则**：先粗后细、尽早退出、避免昂贵运算、利用连贯性、鲁棒性。

**加分点**：指出 k-DOP 测试是"保守"的（只测面法向，不含棱叉积），因此 k 要大些。
