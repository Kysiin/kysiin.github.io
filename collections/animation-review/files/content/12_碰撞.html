12.1 碰撞处理包括哪三个问题

问题 英文 要回答什么 输出
① 碰撞检测 collision detection "两个物体是否相交？何时相交？" 布尔结果 / 首次碰撞时间（TOI）
② 碰撞确认（确定） collision determination "交在哪里？法向是什么？穿透多深？接触区域多大？" 接触点、法向、穿透深度、接触流形（contact manifold）
③ 碰撞响应 collision response "相交后运动/形状如何改变？" 新的速度/位置/形变（反弹、摩擦、约束、形变）

三个问题层层递进：检测决定"要不要处理"，确认给出"处理的几何数据"，响应决定"怎么处理"。实际系统还包含加速结构（broad phase）与更新/剔除等工程问题，但理论核心是这三个。

12.2 碰撞检测中如何选择包围体

包围体（bounding volume） 是包住物体的简单几何体，用于快速排除明显不相交的物体对（broad phase）。选择时权衡四个指标：

指标 含义
紧致性（tightness） 包围体越贴合物体，"误报"越少（narrow phase 调用越少）
测试速度 两个包围体求交的开销
更新速度 物体运动后重新计算包围体的开销（动态场景很关键）
内存 / 构建时间 存储与预处理成本

常见包围体对比：

包围体 紧致性 求交测试 动态更新 适用
球（sphere） 最差 最快（中心距 < r₁+r₂，可避免开方） 最快（中心 + 半径） 快速粗测、粒子、球形物体、远处 LOD
AABB（轴对齐包围盒） 较差 很快（6 次比较） 快（顶点 min/max；刚体变换只算 8 角点） 通用 broad phase、场景树、布料/粒子
OBB（有向包围盒） 好 较慢（SAT 15 轴） 慢（需随物体旋转） 细长/旋转物体、需要紧致时
k-DOP 可调（k 越大越紧） 快（k 个区间重叠，纯比较） 中（顶点投影 O(nk)，但轴向固定不需重算轴） 通用、可控精度、动态场景
凸包（convex hull） 最好 最慢 最慢 少量关键物体、离线
BVH（层次包围体树） —— 树遍历 log n 中 复杂场景/网格（如三角形 soup）

选择原则：

  1. 形状：球状物体用球；细长/倾斜物体用 OBB 或 k-DOP；接近立方体用 AABB 就够；
  2. 运动方式：频繁旋转的物体，AABB/球/k-DOP（轴固定）更新更便宜；OBB 要跟着转；
  3. 精度需求：需要少误报 → 用更紧的（k-DOP 26、凸包）；只要粗筛 → 球/AABB；
  4. 组合使用（层次化）：先用球/AABB 做 broad phase，再用 OBB/k-DOP/精确三角形测试做 narrow phase；场景级用 BVH/八叉树/均匀网格；
  5. 规模与硬件：大规模/GPU 并行时偏好结构规整、可向量化的 k-DOP/AABB。

k-DOP 的独特优势：方向集固定，物体无论怎么转，"轴"都不用重算，只需重新投影顶点（或对 8 个极值点做变换），因此在动态场景中既紧致又便宜，是 AABB 与凸包之间的"可调折中"。

12.3 离散有向多面体 k-DOP 的定义与轴的选择

定义：k-DOP（k-Discrete Oriented Polytope）是由 k/2 对平行平面围成的凸多面体，所有平面的法向取自一个固定的方向集合

物体被表示为它在这 k/2 个方向上的投影区间：对每个方向 d_j，存两个值

即 k 个标量（k/2 个 min + k/2 个 max）。当 k=6 时退化为 AABB（方向为 ±x, ±y, ±z）。

轴（方向）的选择：

k 方向集合 说明
6 (±1,0,0), (0,±1,0), (0,0,±1) 即 AABB，最松
14 6 个面法向 + 8 个顶点方向 (±1,±1,±1) 比 AABB 紧，测试 14 个区间
18 6 + 12 个棱方向 (±1,±1,0), (±1,0,±1), (0,±1,±1) 常用折中
26 6 面 + 12 棱 + 8 顶点 = 26 个方向（13 对） 最紧的常用 k-DOP，接近凸包

选择原则：

  • k 越大越紧致、误报越少，但存储与测试成本越高；实践中 18-DOP / 26-DOP 最常用；
  • 方向应尽量均匀覆盖所有可能朝向（面、棱、角），这样对任意姿态的物体都贴合得好；
  • 常用归一化方向（如 (1,1,0)/√2），但不必归一化也能用（只要一致）；
  • 对特定物体可定制方向（如沿主成分轴），但会失去"轴固定、不需重算"的优势。

性质：k-DOP 是 AABB（k=6）与凸包（k→∞）之间的连续族；求交只需逐方向的区间重叠测试；支持层次包围体（k-DOP 树）。

12.4 碰撞检测中的分离轴定理（SAT）

定理（Separating Axis Theorem）：两个凸多面体不相交，当且仅当存在一条轴（分离轴），使两者在该轴上的投影区间不重叠。

候选轴（对多面体 A、B）：

  1. A 的每个面的法向（3 个，对盒子）；
  2. B 的每个面的法向（3 个）；
  3. A 的每条棱 × B 的每条棱（3×3 = 9 个叉积方向）。

对 OBB vs OBB 共 3+3+9 = 15 个轴；对 AABB 只需 3 个坐标轴。

测试方法：对每个候选轴 n（单位化），计算两个多面体所有顶点在 n 上的投影的最小/最大值，若存在某个 n 使

则不相交（可立即退出）；若所有轴都重叠，则相交。

穿透深度 / MTD：所有轴中"重叠量最小"的那个轴，其重叠量即最小平移距离（Minimum Translation Distance），方向为推出方向——可用于碰撞响应。

优缺点：通用、无需显式求交线、可早退出、可给出 MTD；但轴数随棱数平方增长（复杂多面体很贵），且只适用于凸体（凹体需分解为凸块）。k-DOP 的求交可以看作 SAT 在"固定方向集"上的特例（只测 k/2 个方向，故意忽略棱叉积，用更多固定方向补偿）。

12.5 如何构建多面体模型的 AABB 与 k-DOP 包围盒

AABB 构建：

  1. 遍历（或变换后遍历）模型所有顶点 v_i = (x_i, y_i, z_i)；
  2. 对三个坐标分别取最小值与最大值：
  3. 得到 8 个角点（由 min/max 组合），即 AABB；
  4. 动态更新：刚体变换时，可把 8 个角点变换后重新取 min/max（比变换所有顶点便宜）；只平移时直接平移 min/max。

k-DOP 构建：

  1. 给定方向集 D = {d_1, …, d_{k/2}}（预先归一化）；
  2. 对每个方向 d_j，遍历所有顶点计算点积 d_j·v_i，取最小值与最大值：
  3. 存储 k 个标量（外加方向集共享）；
  4. 动态更新：只需对支持点（极值点）重新投影，或对全部顶点做变换后重新求 min/max；因为方向固定，不需要像 OBB 那样重算轴；
  5. 紧致化：先求凸包再投影（更紧但更贵），或利用物体局部坐标预计算、只对变换后的 8 个"极值顶点"投影。

层次结构：把多个 k-DOP 组织成树（k-DOP 树），自顶向下测试，可把 O(n²) 的物体对测试降到近 O(n log n)。

12.6 求交测试的重要规则

写求交代码/答题时的经验法则（"重要规则"）：

  1. 先粗后细、层次化（broad phase → narrow phase）：先用包围体/空间划分排除绝大多数物体对，只对可能相交的做精确测试；
  2. 尽早退出（early exit）：一旦能判定"不相交"立即返回，不要算完所有条件；
  3. 避免昂贵的运算：优先用比较、乘加，避免除法、开方、三角函数；例如球求交比较距离平方而非距离；
  4. 先做最便宜/最可能失败的测试：例如 AABB 先测重叠概率最低的轴，k-DOP 先测最容易分离的方向；
  5. 利用空间/时间连贯性（coherence）：缓存上一帧的结果、使用增量更新、按空间排序；
  6. 预计算与共享：方向集、平面方程、三角形法向、逆矩阵等只算一次；
  7. 数值鲁棒性：用 epsilon 处理边界情形、避免除零（平行/退化）、注意浮点误差；必要时用区间算术/精确谓词；
  8. 只做必要的精确测试：narrow phase 只在 broad phase 命中后调用；远距离物体用 LOD 包围体；
  9. 保持对称性/一致性：A vs B 与 B vs A 结果一致，避免"谁先测"导致的不同；
  10. 可并行/向量化：数据布局（SoA）与批处理对性能影响很大。

12.7 射线／平板层相交法（ray / slab method）

思想：AABB（或 k-DOP）可看成若干"平板层（slab）"的交——每个方向 d_j 对应一对平行平面 d_j·x = min_j 与 d_j·x = max_j。射线与包围盒相交 ⟺ 射线与所有平板的交区间有公共部分。

算法（射线 p(t) = o + t·dir，t ≥ 0）：

  1. 初始化 t_near = 0（或 −∞），t_far = +∞；
  2. 对每个方向 j： - 计算射线与两个平面的参数： - 若 t₁ > t₂ 交换（保证 t₁ ≤ t₂）； - 更新区间：t_near = max(t_near, t₁)，t_far = min(t_far, t₂)； - 若 t_near > t_far → 无交，退出；
  3. 全部平板处理完仍有 t_near ≤ t_far → 相交，t_near 为入射点参数（t_far 为出射点）。

关键细节：

  • 当 d_j·dir = 0（射线平行于该平板）时：若 o 在该平板区间外 → 无交；否则该平板不限制 t（跳过）；
  • 除法可优化为乘法（保存 1/(d_j·dir)）；同一方向可复用于多个包围盒；
  • 对 AABB 只需 3 个轴（x、y、z），对 k-DOP 需 k/2 个方向；
  • 这是所有包围体射线测试的通用框架，也是"射线求交"的最基础方法。

12.8 射线／三角形相交测试（Möller–Trumbore 算法）

问题：射线 p(t) = o + t·dir 与三角形 (v₀, v₁, v₂) 是否相交？求 t 与重心坐标 (u, v)。

推导思路：把交点写成重心形式 o + t·dir = (1−u−v)v₀ + u·v₁ + v·v₂，整理成线性方程组，用 Cramer 法则求解。

算法：

  1. 边向量：e₁ = v₁ − v₀，e₂ = v₂ − v₀；
  2. pvec = dir × e₂，det = e₁ · pvec； - 若 |det| < ε（或 det ≤ 0，取决于单/双面）→ 射线与三角形平行/共面，无交；
  3. inv_det = 1/det；tvec = o − v₀；
  4. u = (tvec · pvec) · inv_det；若 u < 0 或 u > 1 → 无交；
  5. qvec = tvec × e₁；v = (dir · qvec) · inv_det；若 v < 0 或 u + v > 1 → 无交；
  6. t = (e₂ · qvec) · inv_det；若 t < ε → 交点在射线起点之后才有效（t ≥ 0 为相交）。

优点：一次求解同时得到 t 与重心坐标 (u, v)（可用于插值属性）；无需求平面方程、无需投影到二维；只有乘加与一次除法；速度与存储高效，是工业标准。

应用：光线追踪、鼠标拾取、连续碰撞检测（把粒子/点的运动当作射线）。

12.9 AABB／AABB 相交测试

原理：两个 AABB 相交 ⟺ 在 x、y、z 三个轴上的投影区间都重叠（一维区间重叠的"与"）。

公式：

实现：6 次比较即可（或写成 |c_A − c_B| 与半长之和的分量比较）：

if (A.max.x < B.min.x || B.max.x < A.min.x) return false;
if (A.max.y < B.min.y || B.max.y < A.min.y) return false;
if (A.max.z < B.min.z || B.max.z < A.min.z) return false;
return true;

延伸：

  • 穿透深度（MTD）：三个轴的重叠量 Δx、Δy、Δz 中最小的一个，方向为对应轴的推出方向；
  • 这正是 SAT 在 3 个轴上的特例；
  • 加 epsilon 处理"刚好接触"的退化情况。

12.10 k-DOP／k-DOP 相交测试原理

原理：与 AABB 完全同构，只是把"3 个轴"换成"k/2 个固定方向"。两个 k-DOP 相交 ⟺ 在每一个方向上的投影区间都重叠：

实现：对 j 逐个测试

if (A.max[j] < B.min[j] || B.max[j] < A.min[j]) return false;   // 该方向分离

全部通过则相交；一旦某个方向分离立即返回（early exit）。

要点：

  • 只需 k 次比较（每方向 2 次），与 k 线性，非常快；
  • 因方向集固定，两个 k-DOP 可以直接比较——不需要像 OBB 那样构造 15 个轴；
  • 分离轴定理的特例：只用了"面法向"这一类轴，忽略了棱叉积，因此 k-DOP 测试是保守的（可能把实际不相交的判为相交），需要用更大的 k（18/26）来减少误报；
  • 可给出 MTD：所有方向中重叠量最小者；
  • 对层次 k-DOP 树，按树遍历可加速。

12.11 碰撞响应的三类方法（补充，常与检测一起考）

方法 做法 特点
冲量法（impulse-based） 在接触点沿法向施加冲量使相对法向速度反向（含恢复系数 e 与摩擦），同时更新角速度 适合刚体、可处理多接触、无穿透；需迭代求解
罚函数法（penalty） 用弹簧-阻尼力把穿透的物体推开：F = k·δ − c·v_n（δ 为穿透深度） 简单，但需小步长、可能不稳定/抖动
位置修正/投影（projection） 直接把物体沿法向移出穿透（可加摩擦位移） 稳定、简单，常用于布料/粒子；会"抹掉"能量
约束求解（constraint-based） 把"不穿透"作为约束，用 LCP/序列冲量/位置约束迭代求解 工业级物理引擎主流，稳定可堆叠

连续碰撞检测（CCD）：高速物体一步内可能"穿过"薄壁，需把运动看作线段/扫掠体，求首次碰撞时间（TOI）并在此刻分割步长（保守推进 conservative advancement）。

考点：三个问题、包围体选择、k-DOP 定义与轴、SAT（含 15 轴）、射线/平板层、射线/三角形、AABB/AABB、k-DOP/k-DOP——公式与"为什么快/为什么保守"。
