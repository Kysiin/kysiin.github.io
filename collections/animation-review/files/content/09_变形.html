9.1 Deformation 与 Morphing 的区别

维度 Deformation（变形） Morphing（渐变）
对象 一个物体的形状改变 两个（或多个）物体之间的过渡
输入 一个模型 + 变形规则（骨骼、场、控制点、力） 两个模型 + 对应关系 + 时间参数 t
是否需要对应 不需要 需要（顶点/特征对应）
拓扑 通常拓扑不变（只移动顶点） 可能改变拓扑（分裂/合并/穿孔）
参数 变形参数（权重、控制点位置、力） 单一时间 t
数学 v′ = D(v)，D 为空间/表面映射 v(t) = 插值(v₀, v₁)
典型例子 角色肌肉变形、FFD、布料、表情、cage 变形 人脸从 A 变成 B、正方体变成球、三维模型间过渡
关系 —— Morphing 可以看作"以 t 为参数的、跨两个物体的变形"，但 morphing 额外要求对应与拓扑处理

一句话：变形是"同一物体被施加变形函数"，morphing 是"两个物体之间做插值过渡"。变形关注"如何改变一个形状"，morphing 关注"如何在两个形状之间走一条合理路径"。

9.2 与物体表示无关的变形（representation-independent deformation）

思想：把变形定义在物体所在的空间上，而不是定义在物体的表示（多边形、点云、隐式曲面）上。变形是空间映射

物体的每个点（无论来自哪种表示）都经过同一个 D 变换，因此：

  • 与表示无关：多边形、NURBS、点云、粒子、甚至体数据都可以用同一套变形；
  • 保持连续性：只要 D 连续，变形后的物体仍连续、拓扑不变；
  • 可组合：多个变形可以串联/并联（先弯曲再扭转）；
  • 可逆：D 若是一一映射则有逆映射，可用于法线变换、纹理坐标、碰撞查询。

优点：通用、实现简单（只需对顶点做函数求值）、保持拓扑与连续性、可任意叠加。 缺点：不理解物体的内在结构（不知道哪里是关节、哪里是骨架），难以做"沿骨架的肌肉变形"；大变形时容易失真、自交、体积不守恒；对局部细节的控制依赖控制结构（如 FFD 控制点）。

代表方法：全局变形（Tapering / Twisting / Bending）、自由变形 FFD、Cage 变形、空间扭曲（warp）、晶格变形；与之相对的是基于物体内在结构的变形（骨骼蒙皮、基于 Laplacian 的保细节变形、基于物理的变形）。

9.3 Tapering、Twisting 与 Bending 变形的原理

这三者是 Barr（1984）提出的全局空间变形（global deformation），作用在整个物体上，形式简单、可解析、可逆。

9.3.1 锥化 / 渐变缩放（Tapering）

思想：沿某一轴（设为 z）线性地缩放垂直于该轴的截面，使物体一端粗、一端细。

其中 k 为锥化系数、L 为沿 z 的长度（也可用非线性的 f(z)）。k>0 时上粗下细，k<0 时上细下粗。

用途：树干、锥形瓶、柱状角色肢体、把圆柱变锥体。

9.3.2 扭转（Twisting）

思想：绕某一轴（z）旋转，且旋转角随高度线性增加（像拧毛巾）。

用途：拧麻花、螺旋、毛巾、藤蔓、角色躯干扭转。

9.3.3 弯曲（Bending）

思想：把沿 z 方向的直杆弯成一段圆弧。设总弯曲角为 θ、长度为 L，则曲率半径 R = L/θ。中性轴（x=0）上的点被映射到半径 R 的圆弧上，距中性轴 x 处的点半径为 (R − x)：

注意：弯曲是非均匀的——内侧受压、外侧受拉，因此严格来说不保持长度与体积（这正是物理上正确的行为）；若要求"保长度"，需用保长弯曲（弧长参数化）。

三者对比：

变形 变换形式 保什么 典型用途
Tapering 截面缩放随高度变化 不保体积 锥形、树干、肢体
Twisting 绕轴旋转随高度变化 保长度、不保方向 螺旋、拧毛巾
Bending 直杆弯成圆弧 近似保长度 弯曲的杆、脊柱、树枝

三者可组合（先锥化再弯曲），也可作用于任意表示（因为它们只依赖坐标）。

9.4 自由变形（FFD）的变形原理

提出：Sederberg & Parry（1986），"Free-Form Deformation of Solid Geometric Models"。FFD 是"与表示无关的变形"的典型代表。

基本思想：把物体嵌入一个由控制点构成的长方体（平行六面体）晶格（lattice）中，用三变量 Bernstein 多项式定义从晶格参数空间到物理空间的映射；移动控制点，映射随之改变，物体被光滑地"揉捏"。

步骤：

  1. 构造控制晶格：在物体外包围一个平行六面体，用三个正交方向向量 S、T、U 与原点 X₀ 定义，把它划分为 l×m×n 个格子，得到 (l+1)(m+1)(n+1) 个控制点 P_{ijk}；
  2. 求局部坐标（逆映射）：把每个顶点 X 表示为 解出 (s, t, u) ∈ [0,1]³（即顶点在晶格中的归一化坐标）。这一步是解 3×3 线性方程组，只做一次；
  3. 移动控制点：把 P_{ijk} 改为 P′_{ijk}（用户交互拖拽）；

性质与优点：

  • 与物体表示无关：只对点做映射，任何表示都适用；
  • 光滑：Bernstein 多项式是 C^∞ 的，变形结果光滑（不产生折痕）；
  • 局部控制：移动某个控制点主要影响其附近区域（但 Bernstein 基是全局支撑，影响范围比 B 样条大）；
  • 保凸/包络：结果位于控制点的凸包内；
  • 可组合：多个 FFD 晶格可串联（复合变形）；
  • 实现简单、交互直观：像捏橡皮泥。

缺点：

  • 需要逆映射（把顶点映到参数空间），晶格若变形过大/不正交，逆映射可能失败；
  • 控制点移动是全局影响（一个控制点影响整个物体，只是权重不同），精细局部控制需要加密晶格；
  • 大变形时物体可能自交、体积失真；
  • 不适合表达"基于结构"的变形（如关节弯曲处的肌肉鼓起）；
  • 控制点位置与物体表面的关系不直观（控制点不在表面上）。

9.5 扩展的 FFD 方法（EFFD）的原理

EFFD（Extended Free-Form Deformation）：Coquillart（1990）针对 FFD 的两点限制（晶格必须是平行六面体、控制点移动全局影响）提出的扩展。

核心改进：

  1. 任意形状的晶格：控制网格不再要求是平行六面体，可以是任意形状的六面体网格（甚至贴合物体表面），因此可以构造更"贴身"的控制笼，减少无关区域的影响、提高局部控制能力；
  2. 复合与细分晶格（composite / subdivided lattices）：允许把多个晶格拼接/嵌套（共享面保证连续性），或对晶格局部细分（在需要精细控制的区域加密控制点，其余区域保持稀疏），从而兼顾"全局大形"与"局部细节"；
  3. 参数化方式改变：不再用单一三变量 Bernstein，而是对每个子六面体做局部参数化与映射，通过共享界面保证 C⁰/C¹ 连续。

优点：控制更灵活、能贴合复杂形状、局部性好、可用稀疏控制点做大形 + 细分做细节。 缺点：晶格构造麻烦（需要手工/半自动生成贴合网格）；映射与逆映射复杂、计算量大；拼接处连续性与参数化一致性需要处理；实现难度高。

9.6 基于 Cage 的变形原理、齐次坐标与 Green Coordinates

Cage（控制笼）：包住物体的一层低模封闭网格（顶点 c_i、面 f_j）。用户只移动 cage 顶点，物体随之变形——用少量控制点实现"整体 + 局部"的变形。

优点：保形性好（弯曲、扭转时体积与角度保持得更好）、与表示无关、实时（预计算后每帧线性组合）、可控（移动 cage 顶点 + 调整面法向）。 缺点：需要 cage 的面法向参与，实现比 MVC 复杂；cage 必须封闭且较贴合物体；大变形仍可能自交；对 cage 的拓扑/质量敏感。

考点：cage 坐标的定义式（Σφ=1、p=Σφc）、齐次形式、MVC 的权重公式、Green 坐标多出的"法向项"及其"保形"作用。
