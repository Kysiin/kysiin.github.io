# 第四部分　物体朝向的表示与四元数

## 3.1 为什么"朝向"需要专门表示

物体的**姿态（orientation/attitude）**有 3 个自由度，但不同表示法的参数个数不同（9、3、3、4、4）。动画中要在两个朝向之间**平滑插值**、要能**复合旋转**、要**避免奇异**，因此不同表示各有取舍。大纲要求掌握五种：**旋转矩阵、定角（fixed angles）、欧拉角、轴线角（axis-angle）、四元数**。

| 表示法 | 参数个数 | 是否唯一 | 插值 | 主要问题 |
|---|---|---|---|---|
| 旋转矩阵 | 9（实际 3 DOF） | 唯一 | 不能直接线性插值 | 冗余大、需正交化、累积误差 |
| 定角（fixed angles） | 3 | 一般不唯一 | 可插值但有奇异 | 万向节死锁、依赖顺序 |
| 欧拉角（Euler angles） | 3 | 一般不唯一 | 可插值但有奇异 | 万向节死锁、插值路径不自然 |
| 轴线角（axis-angle） | 4 | 唯一（θ∈[0,π]） | 可插值 | 复合旋转不方便、θ=0 时轴无定义 |
| 四元数（quaternion） | 4（单位） | 双重覆盖（q 与 −q） | **Slerp 平滑** | 需归一化、不直观 |

## 3.2 旋转矩阵（Rotation Matrix）

3×3 正交矩阵 R，满足 RᵀR = I、det(R) = +1（属于特殊正交群 SO(3)）。三个列向量（或行向量）是旋转后坐标系的基向量。

$$
R = \begin{bmatrix} r_{11} & r_{12} & r_{13} \\ r_{21} & r_{22} & r_{23} \\ r_{31} & r_{32} & r_{33} \end{bmatrix}
$$

矩阵形式写作（行主序单行形式便于记忆）：

```
R = [ r11  r12  r13 ]
    [ r21  r22  r23 ]
    [ r31  r32  r33 ]
```

三个基本旋转（绕 X、Y、Z 轴转 θ，右手系）：

```
Rx(θ) = [ 1   0      0    ]      Ry(θ) = [ cosθ  0  sinθ ]      Rz(θ) = [ cosθ -sinθ 0 ]
        [ 0  cosθ  -sinθ ]              [  0    1   0   ]              [ sinθ  cosθ 0 ]
        [ 0  sinθ   cosθ ]              [-sinθ  0  cosθ ]              [  0     0   1 ]
```

**优点**：可直接变换向量（v' = Rv）；复合旋转 = 矩阵相乘；与图形管线（法线变换、视图矩阵）一致。
**缺点**：9 个参数只有 3 个自由度（6 个正交约束），存储冗余；反复相乘会累积浮点误差导致不再正交，需要 Gram-Schmidt 重新正交化；**不能直接对矩阵元素做线性插值**（插值后不再是旋转矩阵，会导致缩放/剪切）；不能直观看出"绕哪个轴转多少度"。

## 3.3 定角表示（Fixed Angles）

**定义**：绕**固定不动的参考系（世界坐标轴）**依次旋转三个角。记作 Fixed(α, β, γ)，如 X-Y-Z 顺序表示：先绕世界 X 轴转 α，再绕世界 Y 轴转 β，最后绕世界 Z 轴转 γ。

**关键性质**：定角 X-Y-Z 等价于**动轴欧拉角的逆序** Z-Y-X（intrinsic），即

$$
R_{\text{fixed}}(X,Y,Z;\ \alpha,\beta,\gamma) = R_z(\gamma)\,R_y(\beta)\,R_x(\alpha)
$$

注意矩阵相乘的顺序与旋转发生顺序相反（后转的乘在左边），这是最容易出错的地方。

**缺点**：同样存在万向节死锁；三个角的含义依赖顺序约定（必须声明 X-Y-Z 还是 Z-Y-X），不同软件/教材约定不同（Maya 的 rotate order、Blender 的 XYZ Euler）。

## 3.4 欧拉角（Euler Angles）

**定义**：绕**随物体一起转动的自身坐标轴（body axes）**依次旋转三个角，如 Z-Y-X（先绕自身 Z，再绕新的 Y，再绕新的 Z…顺序按约定）。

**与定角的关系**：定角 X-Y-Z ≡ 欧拉角 Z-Y-X（同一矩阵），二者只是"以哪个观点看"的区别：定角站在世界坐标看，欧拉角站在物体坐标看。

**优点**：参数最少（3 个）、直观（"抬头 30°、转向 45°"）、便于设置关键帧、艺术家友好。
**缺点**：
- **万向节死锁**（见 3.6）；
- **多解与不唯一**：同一姿态有无穷多组 (α, β, γ)（如 β 与 π−β 的等价、绕圈加减 360°），插值时会"绕远路"或突然翻转；
- 插值是在角度空间线性进行，得到的运动路径不自然（不是最短旋转）；
- 依赖旋转顺序约定，跨软件易出错。

## 3.5 轴线角表示（Axis-Angle）

**定义**：用一根单位轴 u = (u_x, u_y, u_z) 和一个旋转角 θ 表示绕该轴转 θ 的旋转（θ∈[0, π] 时唯一）。

**Rodrigues 公式**（轴线角 → 矩阵）：

$$
R = I + \sin\theta\,[u]_\times + (1-\cos\theta)\,[u]_\times^{2}, \quad [u]_\times = \begin{bmatrix} 0 & -u_z & u_y \\ u_z & 0 & -u_x \\ -u_y & u_x & 0 \end{bmatrix}
$$

展开得标准形式（哈默斯利）：

```
R = [ c+ux²(1-c)     uxuy(1-c)-uzs   uxuz(1-c)+uys ]
    [ uyux(1-c)+uzs  c+uy²(1-c)      uyuz(1-c)-uxs ]
    [ uzux(1-c)-uys  uzuy(1-c)+uxs   c+uz²(1-c)    ]
其中 c = cosθ, s = sinθ
```

**优点**：物理意义明确（转轴 + 转角），四元数就是它的紧凑形式。
**缺点**：θ=0 时轴无定义（旋转轴不确定）；复合两次旋转需要转成矩阵或四元数；参数仍为 4 个但非单位四元数，插值不如 Slerp 自然。

## 3.6 万向节死锁（Gimbal Lock）

**定义**：在使用三个角度（欧拉角/定角）表示三维旋转时，当**第二个旋转角使第一与第三个旋转轴重合（共线）**时，三个自由度退化为两个——有一个方向上的旋转无法通过改变角度实现，这一现象称为万向节死锁。

**经典例子**（Z-Y-X 欧拉角）：当绕 Y 轴转 β = ±90° 时，原来的 Z 轴被转到 X 轴方向，此时"绕 Z 转"和"绕 X 转"变成同一个效果，第三个参数失去意义，丢失一个自由度。

**表现**：
- 动画中表现为姿态**突然跳变/抖动/翻转**（插值穿过死锁点时急转）；
- 某些朝向**无法到达**，或到达需要剧烈的角度变化；
- 手动旋转时"某一方向怎么转都不对"。

**产生原因**：三个角度是对 SO(3)（三维旋转空间）的某种坐标化（参数化），而 SO(3) 不是平直空间（拓扑上是射影三维球面），任何 3 参数的连续参数化都必然存在奇异点——这由**拓扑性必然性**决定，不是实现 bug。

**解决办法**：

1. 用**四元数**（或轴线角）表示与插值，从根本上避免死锁；
2. 限制中间角范围（避免接近 ±90°），或改用其他旋转顺序；
3. 在动画中用"四元数 + Slerp"做朝向插值，只在界面显示欧拉角；
4. 用矩阵累计旋转、再分解；
5. 分区间/多个姿态混合（pose blending）。

>**考点（高频判断题）**：
>- "万向节死锁是因为欧拉角参数化存在奇异，任何三参数方法都无法避免" —— **对**；
>- "用四元数可以避免万向节死锁" —— **对**（避免的是死锁导致的插值问题，四元数覆盖整个 SO(3) 无奇异）；
>- "万向节死锁只发生在硬件云台上" —— **错**；
>- "四元数只有 3 个参数" —— **错**（4 个，单位约束后 3 个自由度）。

## 3.7 旋转的四元数表示

**定义**：单位四元数 q = (w, x, y, z) = w + xi + yj + zk，满足 w² + x² + y² + z² = 1，其中

$$
q = \left(\cos\frac{\theta}{2},\ \sin\frac{\theta}{2}\,u_x,\ \sin\frac{\theta}{2}\,u_y,\ \sin\frac{\theta}{2}\,u_z\right)
$$

即绕单位轴 u 转 θ。对应的共轭 q* = (w, −x, −y, −z) 表示**逆旋转**（单位四元数的逆等于共轭）。

**基本运算**：

$$
q_1 q_2 = \left(w_1 w_2 - \mathbf{v}_1\cdot\mathbf{v}_2,\ \ w_1\mathbf{v}_2 + w_2\mathbf{v}_1 + \mathbf{v}_1\times\mathbf{v}_2\right)
$$

**用四元数旋转向量**（v = (x,y,z) 视为纯四元数 (0, v)）：

$$
\mathbf{v}' = q\,\mathbf{v}\,q^{*}
$$

**四元数 → 旋转矩阵**：

```
R = [ 1-2(y²+z²)   2(xy-wz)     2(xz+wy)   ]
    [ 2(xy+wz)     1-2(x²+z²)   2(yz-wx)   ]
    [ 2(xz-wy)     2(yz+wx)     1-2(x²+y²) ]
```

**旋转矩阵 → 四元数**（本课程明确的考点，见 3.8 的完整公式）。

**优点**：
- 只有 4 个参数（1 个约束），比矩阵省空间、复合旋转只需 16 次乘法（矩阵需 27 次）；
- **无万向节死锁**，可表示任意旋转；
- **插值平滑**：Slerp 沿球面大圆弧插值，得到匀速、最短的旋转；
- 数值稳定：只需归一化，不会像矩阵那样失去正交性；
- 求逆 = 取共轭，非常便宜。

**缺点**：
- 不直观（4 个分量无直接几何意义）；
- **双重覆盖**：q 与 −q 表示同一旋转，插值前需判断点积符号取近端（否则会转 360°）；
- 需要归一化（浮点误差会让模长偏离 1）；
- 与欧拉角/矩阵之间的转换有分支和精度问题。

## 3.8 旋转矩阵到四元数的转换公式

设

```
R = [ m00  m01  m02 ]
    [ m10  m11  m12 ]
    [ m20  m21  m22 ]
```

**方法一：迹（trace）法**（当 tr(R) = m00+m11+m22 > 0 时数值最稳定）

$$
w = \frac{1}{2}\sqrt{1 + m_{00} + m_{11} + m_{22}}, \quad
x = \frac{m_{21}-m_{12}}{4w}, \quad
y = \frac{m_{02}-m_{20}}{4w}, \quad
z = \frac{m_{10}-m_{01}}{4w}
$$

**方法二：Shepperd 分支法**（当迹接近 0 或为负时，上式分母趋 0 会丢失精度，需选最大的对角元分支）

```
tr = m00 + m11 + m22
若 tr > 0:
    S = sqrt(tr + 1) * 2          # = 4w
    w = 0.25 * S
    x = (m21 - m12) / S
    y = (m02 - m20) / S
    z = (m10 - m01) / S
否则若 (m00 > m11 且 m00 > m22):
    S = sqrt(1 + m00 - m11 - m22) * 2   # = 4x
    w = (m21 - m12) / S
    x = 0.25 * S
    y = (m01 + m10) / S
    z = (m02 + m20) / S
否则若 (m11 > m22):
    S = sqrt(1 + m11 - m00 - m22) * 2   # = 4y
    w = (m02 - m20) / S
    x = (m01 + m10) / S
    y = 0.25 * S
    z = (m12 + m21) / S
否则:
    S = sqrt(1 + m22 - m00 - m11) * 2   # = 4z
    w = (m10 - m01) / S
    x = (m02 + m20) / S
    y = (m12 + m21) / S
    z = 0.25 * S
最后归一化 q = q / ||q||
```

**推导要点**（考试可写）：由 R 的元素与 q 的关系，例如
m00+m11+m22 = 3 − 4(x²+y²+z²) = 4w² − 1，故 w = ½√(1+tr)；
m21 − m12 = 4wx，m02 − m20 = 4wy，m10 − m01 = 4wz，于是得到方法一。
当 w 接近 0 时改为用对角元求 x（或 y、z）再回代，即 Shepperd 分支法。

**注意**：符号约定会影响结果（q 与 −q 等价，所以结果"对"即可，不必纠结符号）；转换前应确保 R 已正交化。

## 3.9 球面线性插值（Spherical Linear Interpolation, Slerp）

**问题**：给定两个单位四元数 q₀、q₁，求 t∈[0,1] 之间的平滑过渡。

**角度与最短路径**：

$$
\cos\theta = q_0 \cdot q_1 = w_0w_1 + x_0x_1 + y_0y_1 + z_0z_1, \quad \theta = \arccos(q_0\cdot q_1)
$$

若 q₀·q₁ < 0，则令 q₁ ← −q₁（取同半球/最短路径，否则会绕远路转 360°）。

**Slerp 公式**：

$$
\mathrm{Slerp}(q_0, q_1, t) = \frac{\sin\big((1-t)\theta\big)}{\sin\theta}\,q_0 + \frac{\sin(t\theta)}{\sin\theta}\,q_1
$$

**性质与说明**：

- 结果在单位球面的大圆弧上，**角速度恒定**（匀速旋转），是"最短、最自然"的旋转插值；
- t=0 得 q₀，t=1 得 q₁；
- 当 θ 很小时 sinθ ≈ θ，公式退化为线性插值（会损失单位性，需归一化）——工程上常用阈值判断避免除零；
- 当 θ = 0（q₀=q₁）时公式除零，需特判返回 q₀；
- 计算量：两次 sin、一次 sin 除法，比线性插值贵，可用 nlerp（归一化线性插值）近似：nlerp(q₀,q₁,t) = normalize((1−t)q₀ + t q₁)，速度略不均匀但可接受、实现简单，是游戏引擎常用折中；
- 应用：角色朝向关键帧插值、摄像机朝向、骨骼旋转、姿态混合、四元数关键帧动画。

>**考点**：写出 Slerp 公式；说明 θ = arccos(q₀·q₁)；说明"若点积为负需取反，避免绕远路"；说明 Slerp 匀速、最短；对比 nlerp。

## 3.10 朝向表示小结（对比表，适合问答）

| 维度 | 旋转矩阵 | 定角 | 欧拉角 | 轴线角 | 四元数 |
|---|---|---|---|---|---|
| 参数 | 9 | 3 | 3 | 4 | 4 |
| 自由度 | 3 | 3 | 3 | 3 | 3 |
| 唯一性 | 唯一 | 多解 | 多解 | θ∈[0,π] 唯一 | 双重覆盖 |
| 死锁 | 无 | 有 | 有 | 无 | 无 |
| 插值质量 | 差（不能直接插） | 中 | 中（角度线性） | 较好 | **最好（Slerp）** |
| 复合 | 矩阵乘 | 转矩阵 | 转矩阵 | 转矩阵/四元数 | 四元数乘 |
| 直观性 | 差 | 中 | **好** | 较好 | 差 |
| 典型用途 | 渲染/变换 | 设定姿态 | 动画曲线通道 | 构造/输出 | 插值与混合 |
