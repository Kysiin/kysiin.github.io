10.1 布料的物理机械性能主要包括哪几种力

布料（织物）在力学上表现为各向异性的薄片，其"手感"与悬垂形态由以下四种基本变形力决定（大纲明确要求）：

力 英文 物理含义 对布料的视觉影响
① 拉伸力 stretch / tension 沿纱线方向抵抗被拉长的力（经纬两个方向不同） 决定布料"抗拉/软硬"，是最主要的力；拉伸刚度大→不易变形
② 压缩力 compression 沿纱线方向抵抗被压短的力 纱线几乎不能承受压缩，受压会失稳起皱（buckling），这是褶皱的根源
③ 剪切力 shear 经纬纱之间夹角改变（由直角变菱形）时产生的抗力 决定布料"斜向的硬度"；剪切刚度大→挺括，小→柔软垂顺
④ 弯曲力 bending 抵抗弯折/卷曲的力 决定"挺括 vs 柔软"：纸/牛仔弯曲刚度大，丝绸小；影响褶皱的尖锐程度

除这四种"内部"力之外，布料动画还要考虑：重力、阻尼（内摩擦/空气阻力）、与物体/自身的碰撞与摩擦、缝线/约束等。

补充（可能考"如何测量"）：织物的力学性能常用 KES（Kawabata Evaluation System） 测量：拉伸、剪切、弯曲、压缩、表面摩擦与粗糙度、厚度与重量，得到一系列"手感指标"。

在质点-弹簧模型中如何对应：拉伸/压缩 → 结构弹簧（structural springs）；剪切 → 对角剪切弹簧（shear springs）；弯曲 → 隔点的弯曲弹簧（bend springs）。这也是下面 Provot 模型的三类弹簧。

10.2 Provot 的衣服模型（质点-弹簧模型 + 应变限制）

提出：Provot（1995），"Deformation Constraints in a Mass-Spring Model to Describe Rigid Cloth Behavior"。

模型构造：

  1. 把布料离散成规则的质点网格（四边形/三角形网格的顶点为质点，质量为 m）；
  2. 在质点之间连接三类弹簧：
弹簧 连接方式 模拟的物理性能
结构弹簧（structural） 相邻格点的水平/垂直连接 拉伸力与压缩力（抗拉、抗压）
剪切弹簧（shear） 每个四边形的两条对角线 剪切力（抗菱变）
弯曲弹簧（bend） 隔一个格点的连接（也可省略） 弯曲力（抗弯折）

Provot 的关键贡献——应变限制（strain limiting / stiffness modification）：

显式积分下，若弹簧刚度大则要求极小步长（否则不稳定）；若刚度小，布料会被过度拉伸（像橡皮筋，出现"超弹性"）。Provot 的做法是：在每步积分后，检查每条弹簧的长度，若超过允许的最大应变，就把两个端点沿弹簧方向直接移动，使长度回到上限：

效果：用较软的弹簧 + 几何约束修正代替"很硬的弹簧 + 极小步长"，既避免数值不稳定，又得到"几乎不可拉伸"的真实布料，是布料模拟中的经典技巧。

优点：模型简单直观、参数（刚度、阻尼）有物理含义、易于实现与加速、配合应变限制效果好。 缺点：弹簧参数依赖网格分辨率（细分后刚度需重调）、各向同性（无法区分经/纬纱的真实结构）、显式积分稳定性受限、不能自然产生真实的屈曲/褶皱细节（需高分辨率与弯曲弹簧）、难以表现塑性/摩擦各向异性。

10.3 布料动画中大步长隐式方法的原理

10.3.1 为什么需要隐式方法

布料（尤其是丝绸、纸）的拉伸刚度极大，弹簧系统的固有频率很高。显式方法的稳定条件近似为

刚度 k 大 → 步长必须极小 → 每帧要做成百上千次小步，计算量巨大（高分辨率布料无法实时）。

隐式方法把力的计算放在未知的未来时刻，从而无条件稳定（理论上任意步长都不"爆炸"），可以用大步长。

求解： - 系数矩阵 M + hC + h²K 是稀疏、对称正定矩阵 → 用共轭梯度（CG）、Cholesky、多重网格、预条件子求解； - 每步需求解一次大型稀疏线性系统；碰撞/摩擦/自碰撞使系统非线性，需牛顿迭代/局部线性化或约束求解（如 Projective Dynamics 的局部-全局交替）。

优点：无条件稳定，可用大 h（例如 1/30 s 一步）模拟高刚度布料；步长增大不会"炸开"；适合实时/大场景。 缺点：每步计算量大（稀疏线性求解）；数值耗散（过度阻尼）——布料显得"黏"、失去弹性；大变形/碰撞时线性化误差大，需迭代；实现复杂。

10.3.3 自适应调整步长

固定大步长虽稳定，但在剧烈变形/高速碰撞/强拉伸区域精度不足，在平缓运动区域又浪费计算。因此常用自适应步长：

  1. 按局部误差估计调整：比较一步与两步（或高低阶方法）结果之差，误差大则减小 h，误差小则增大 h（类似自适应 Runge–Kutta）；
  2. 按 CFL/应变条件：监测最大速度、最大应变率或最小边长，令 ，保证一个步长内质点不穿过网格/不产生过大应变；
  3. 按事件（碰撞）驱动：检测到即将发生碰撞时细分到碰撞时刻（event-driven / 时间步二分）；
  4. 硬约束/位置修正配合：大步长后用应变限制（Provot 式）或多重网格修正位置，把误差"投影"掉；
  5. 空间自适应：对褶皱剧烈区域用细网格/小步长（多分辨率布料）。

优点：在保证稳定与精度的前提下尽量减少计算；兼顾效率与质量。 缺点：步长频繁变化使时间积分不光滑（可能产生抖动）；误差估计与切换逻辑增加实现复杂度；并行化困难（不同区域步长不同）。

考点：隐式欧拉公式与"无条件稳定"的结论；线性化后的稀疏系统与求解方法；数值耗散的缺点；自适应步长的三类依据（误差、CFL/应变、碰撞事件）；以及"显式 vs 隐式"的权衡。
