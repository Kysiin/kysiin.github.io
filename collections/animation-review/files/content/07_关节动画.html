第八部分　关节动画：正向运动学与逆向运动学

下载 PDF离线 / 打印版

7.1 关节、骨架与自由度

  • 骨架（skeleton）：由关节（joint）与连接关节的骨段（bone/segment）组成的树状结构，从根关节（root）出发逐级相连；
  • 关节类型：转动关节（铰链，1 DOF）、移动关节（滑轨，1 DOF）、球关节（3 DOF）、万向节（2 DOF）、固定关节（0 DOF）；
  • 自由度（DOF）：整个骨架的自由度 = 各关节自由度之和，n 个关节角构成关节向量 q ∈ Rⁿ；
  • 末端执行器（end effector）：需要控制位置/朝向的末端（手、脚、工具尖端）。

两个空间：

关节空间（joint space / configuration space） 笛卡尔空间（Cartesian space / task space）
表示 各关节角度/位移 q ∈ Rⁿ 末端位姿 x ∈ R⁶（位置 3 + 朝向 3）或 R³
优点 维数等于自由度、无奇异、便于插值与关键帧、计算简单 直观：直接指定"手放在桌上"；便于与场景/物体交互、便于约束
缺点 不直观，难精确控制末端；需处理关节限位 映射非线性；可能多解、无解、奇异；计算慢
动画中的角色 关键帧插值、动作捕捉数据、曲线编辑 用户交互（拖手）、目标约束、IK 的目标定义

动画流程的典型做法：用户在笛卡尔空间给出目标（把手放到杯子上）→ 用 IK 解出关节角 → 在关节空间里做插值/平滑/加缓动 → 再用 FK 计算各骨骼的世界变换 → 蒙皮渲染。

7.2 正向运动学（Forward Kinematics, FK）

定义：已知所有关节的角度 q（以及骨段长度、关节局部变换），求末端执行器的位姿。

数学形式：沿运动链依次相乘齐次变换矩阵

（T_i 由关节类型决定：转动关节为绕轴旋转 + 沿骨段的固定平移；移动关节为沿轴平移。工业机器人常用 D-H 参数描述。）

特点：

  • 唯一、直接、稳定：给定 q 一定有唯一 x；计算量 O(n)；无奇异、无多解问题；
  • 适合播放：动捕数据、关键帧都是关节角，用 FK 逐帧算骨骼矩阵，非常适合实时；
  • 缺点：控制末端困难——想让手碰到目标，只能不断试角度（试错）；不能自动满足"脚不滑、手固定"等约束。

基于 FK 的动画：给每个关节的角度设关键帧 + 插值曲线；用 FK 算出世界矩阵；骨骼层级自动带动子关节（父动子随）。

7.3 逆向运动学（Inverse Kinematics, IK）

定义：已知末端目标位姿 x_d（位置 + 朝向），求关节角 q 使得

难点（问答题常考"为什么 IK 难"）：

  1. 非线性：f 是三角函数/矩阵的复合，方程非线性，无通用解析解；
  2. 多解：同一末端位置可有多组关节角（肘部朝上/朝下、手腕翻转）——需要选"最自然"的解并保证帧间连续（不能突然翻转）；
  3. 冗余（redundancy）：n > 6 时有无穷多解，多余自由度可用于次级目标（避障、姿态自然、关节限位）；
  4. 可能无解：目标超出可达范围（工作空间外）；
  5. 奇异位形（singularity）：某些姿态下雅可比降秩，末端某些方向无法移动，数值方法会"卡住/爆炸"；
  6. 关节限位：解必须落在 [q_min, q_max] 内；
  7. 计算与实时性：迭代法需要多次迭代与矩阵求逆。

分类：

类别 方法 适用
解析法 几何/代数闭式解（两连杆、球腕） 结构简单、特定构型；快、可求全部解
数值迭代法 逆雅可比（伪逆/DLS）、CCD、FABRIK 通用、任意骨架
优化法 最小化目标函数 + 约束（LM/SQP） 需多约束、离线或后处理
基于样例 从数据库检索/插值 需自然真实的表演
学习法 神经网络回归关节角/姿态先验 单目视觉、实时估计

  1. 计算当前末端位姿 x = f(q)，误差 e = x_d − x；

零空间（null space）利用：冗余时

第二项位于 J 的零空间，不改变末端位置，可用于满足次级目标：关节限位、姿态自然（贴近参考姿态）、避障、保持重心、平滑。

优点：通用（任意 DOF 与骨架）、能利用冗余做次级任务、数学清晰、可与物理/约束结合。 缺点：需计算雅可比与矩阵求逆（O(n³)）；只做局部线性化，大步长会震荡、小步长收敛慢；奇异附近需阻尼；可能陷入局部极小或不收敛；关节限位需额外处理（截断/投影）。

7.5 循环坐标下降法（CCD, Cyclic Coordinate Descent）

思想：不去解整个雅可比系统，而是一次只调一个关节，从末端向根部依次处理，每步都让"当前末端→目标"的误差在该关节的旋转下最小。

单步（对第 i 个关节）：

  1. 计算从关节 i 到末端的向量 u = p_end − p_i，从关节 i 到目标的向量 v = p_target − p_i；
  2. 求把 u 转到 v 的旋转：转轴 = u × v（归一化），转角 = arccos(û·v̂)（二维中直接是角度差 atan2）；
  3. 把该旋转应用到关节 i（及其所有子关节随之转动），末端随之移动；
  4. 处理下一个关节 i−1（向根部推进）。

外层循环：把上述"从末端到根"的一遍称为一次迭代（cycle），重复多遍直到末端误差小于阈值或达到迭代上限。

优点：实现极简单、无需雅可比与求逆、每次迭代计算量小、对任意 DOF/链长都适用、收敛通常较快（末端关节先对齐）。 缺点：结果不自然——末端关节承担大部分旋转，前面关节几乎不动（"像面条"）；容易受关节限位影响；不保证收敛到精确解；目标不可达时行为不理想；没有全局最优性。

7.6 FABRIK 法的原理

FABRIK（Forward And Backward Reaching Inverse Kinematics）：用位置而非角度迭代，靠"保持骨长"的前后两遍传播来逼近目标，速度很快、稳定、易实现。

流程：

  1. 判断可达性：若 ‖p_target − p_root‖ > Σ l_i（总骨长），目标不可达 → 把所有关节沿"根→目标"方向伸直（尽量靠近），结束；
  2. 后向传播（backward reaching）：把末端放到目标位置，然后沿链往回（向根）逐段重定位：对每个关节 i，令 p_i 位于"从 p_{i+1} 出发、方向为原 p_i−p_{i+1}、长度为 l_i"的位置上（即保持骨长，方向沿用当前方向）；
  3. 前向传播（forward reaching）：把根放回原始位置，再沿链往前逐段重定位：p_{i+1} = p_i + l_i ·（原方向单位向量）；
  4. 重复 2~3，直到 ‖p_end − p_target‖ < ε 或达到迭代上限。

优点：计算量小、收敛快、天然保持骨长、稳定、无需雅可比/矩阵运算、适合实时与游戏/交互。 缺点：只保证末端位置，不直接保证关节限位与朝向；3D 中需要额外的"关节朝向/极向量（pole vector）"控制避免扭转；结果可能不自然（需后处理约束）；对朝向目标（手的方向）需扩展。

7.7 基于优化的 IK 计算方法与目标函数

思想：把 IK 写成一个带约束的非线性优化问题，一次求解同时满足多个目标。

典型目标函数：

各项依次为：末端误差（让末端到达目标）、贴近参考姿态（‖q−q₀‖²，保持自然）、关节限位惩罚（φ(q_i) 在越界时急剧增大）、平滑项（‖q̈‖²，抑制抖动）、避障/姿态先验（Ψ(q)）。

约束：

碰撞（自碰撞环境）约束平衡支撑约束（脚不滑动）

求解：梯度下降、高斯–牛顿、Levenberg–Marquardt、序列二次规划（SQP）、内点法；实时场景常简化为"一次线性化 + 加权最小二乘"。

优点：可同时处理末端、限位、避障、平滑、风格等多个目标；结果自然可控；可加硬约束；可离线求全局解。 缺点：慢（每帧多次迭代 + 约束求解）；权重难调（λ 之间冲突）；可能局部极小；不保证实时；对初值敏感。

7.8 基于样例的 IK（example-based）

思想：不实时求解方程，而是从已有的运动数据（动捕库、姿态库）中检索与当前目标最接近的样例，再插值/拼接出结果。

做法：

  1. 建立姿态/动作数据库（每个样例含关节角 + 末端位置/特征）；
  2. 给定目标，在库中找最近邻（k-d 树、PCA/降维、哈希）；
  3. 对若干近邻做局部插值（散点插值、RBF、加权平均），或按相似性拼接片段；
  4. 用少量 IK 修正残余误差。

优点：结果真实自然、保留表演细节与风格、无需精确物理模型、可实时（检索快）。 缺点：依赖数据覆盖（库外动作无法生成）；数据采集成本高；检索与插值开销；需要处理连续性与足部接触；难以满足精确的末端约束。

7.9 基于深度学习的姿态恢复

任务：从图像/视频/IMU 等输入直接回归 3D 人体姿态（关节位置/角度/参数化模型如 SMPL）。

优点：

  • 成本低：单目相机/手机即可，无需动捕设备与标记；
  • 实时：网络推理快，可实时驱动虚拟角色；
  • 鲁棒：学习到人体结构先验，对遮挡、光照、服装变化有一定鲁棒性；
  • 泛化：可处理自然场景、多人、非受控环境。

缺点：

  • 依赖数据：需要大量带标注（3D/2D 关键点）的数据，标注昂贵；
  • 泛化与域偏移：训练分布外（罕见姿态、特殊服装、极端视角）性能下降；
  • 深度/尺度歧义：单目本质是病态问题，可能"看起来对但深度错"；
  • 时间不一致：逐帧估计会抖动、跳变，需时序平滑；
  • 物理不合理：可能穿地、关节反折、脚滑动，缺少物理约束；
  • 可控性与可解释性差：难以精确指定某个关节角度，调试困难；
  • 难以超越训练数据：不能生成数据中不存在的动作风格。

7.10 FK 与 IK 的优缺点对比

维度 正向运动学 FK 逆向运动学 IK
输入/输出 关节角 → 末端位姿 末端位姿 → 关节角
解的存在性 总有唯一解 可能无解/多解/无穷多解（冗余）
计算 快、稳定、O(n) 慢、迭代、可能不收敛
奇异 无 有（雅可比降秩）
控制直观性 差（试角度） 好（直接指定手/脚位置）
约束/交互 难满足末端约束 易满足末端、接触、避障约束
自然性 关节角曲线由动画师控制，最自然 需加次级目标/限位才自然
典型用途 播放动捕、关键帧、渲染计算骨骼矩阵 交互式摆姿势、脚部固定、抓取、程序化动画

实践结论：FK 负责"表演"，IK 负责"约束"——两者结合（如腿部 IK 保证脚不滑、上身 FK 保留表演），并让 IK 结果再经关节空间平滑后输出。

7.11 数值求解 IK 的方法清单（大纲要求，必背）

  1. 逆雅可比方法（伪逆 / 阻尼最小二乘 DLS，含零空间次级任务）；
  2. 循环坐标下降法（CCD）；
  3. 基于优化的方法（目标函数 + 约束，LM/SQP）；
  4. 基于样例的方法（数据库检索 + 插值）；
  5. FABRIK 法（前向/后向迭代，位置法）。

（此外还有：解析/几何法、遗传算法/模拟退火、神经网络/学习法。）

考点：五个方法名称 + 一句话原理 + 各自优缺点；"IK 有哪几类方法"可答"解析法与数值法（数值法含上述五种）"。
