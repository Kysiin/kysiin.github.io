# MyAes 实验解析

## 一、实验目标

`MyAes.c` 是一份 AES（Rijndael）的教学实现，其中 6 个函数的源码被删除，编译后的机器码被藏进
`aes_lib.lib`（VC6）/ `aes_lib.o`（GCC）。要求：

1. 删除 `#pragma comment(lib, "aes_lib.lib")`，不再链接预编译库；
2. 自己重写这 6 个函数；
3. 使程序能独立编译运行，且输出与原程序**完全一致**。

被删除的 6 个函数：

| 函数 | 作用 |
|------|------|
| `build_sbox_inverse` | 由 S 盒生成逆 S 盒 |
| `aes_polynomial_mul` | GF(2⁸) 上模 (X⁴+1) 的多项式（列）乘法 |
| `ByteSubInverse` | 逆字节替换 |
| `ShiftRowInverse` | 逆行移位 |
| `MixColumnInverse` | 逆列混淆 |
| `aes_decrypt` | 整体解密（`aes_encrypt` 的逆） |

验证结果（与 `readme.txt` 样例逐字节一致）：

```
128-bit: C037F19D4AEA8E7172B176B9D4CE1D62
192-bit: F51C8DD5F7052264650126DC70D402F5
256-bit: 2687C0D61E803718F6D11A0384C81229
```
三种密钥解密均还原出 `A Quick BrownFox`。

编译运行：

```bash
gcc MyAes.c -o myaes      # 已删除 pragma，不再需要 aes_lib
./myaes
```

## 二、读懂这份实现的“非标准”之处

要写对逆函数，关键是先看懂本实现里 `aes_encrypt` 到底做了什么。它和教科书 AES 数学等价，但
用了一个技巧：**靠“转置”在“按行操作”和“按列操作”之间来回切换**。

状态 16 字节按**行主序**看成 4×4 矩阵 `P`，即 `P[i][j] = p[i*4+j]`。已提供的工具函数里：

- `ShiftRow` 对**行**操作（`rol_a_row(p+i*4, i)`，第 i 行循环左移 i）；
- `MixColumn` 对**列**取数（`get_column`），但把结果**写回成行**——所以它隐含了一次**转置**。

`MixColumn(p, a, do_mul)` 的真实语义：

```
取第 j 列 b → (do_mul 时) b = a ⊗ b → 把 b 放到第 j 行
```

记 `T` 为转置、`L_a` 为“逐列左乘多项式 a 的循环矩阵”，则

- `MixColumn(do_mul=0)` = `T`（纯转置）
- `MixColumn(do_mul=1)` = `T ∘ L_a`

`aes_encrypt` 每一轮的步骤是：

```
ByteSub  →  MixColumnInverse(a,0)[=转置]  →  ShiftRow  →  MixColumn(a, do_mul)  →  AddRoundKey
```

其中最后一轮 `do_mul=0`（只转置，不混淆），与标准 AES“末轮无 MixColumns”对应。

## 三、各函数的实现与推导

### 1. `build_sbox_inverse`

S 盒是 GF(2⁸) 上的双射置换，逆盒就是它的反函数：若 `sbox[i] = v`，则 `sbox_inverse[v] = i`。

```c
for (i = 0; i < 256; i++)
    sbox_inverse[sbox[i]] = (unsigned char)i;
```

### 2. `aes_polynomial_mul`：z = x · y mod (X⁴+1)

`x` 是变换多项式的 4 个系数，`y` 是被乘的一列，系数都在 GF(2⁸) 中，
系数相乘用已有的 `aes_8bit_mul_mod_0x11B`（模本原多项式 0x11B），相加即异或。

`aes.txt` 给出系数 `{a0,a1,a2,a3}` 对应的**循环矩阵**。对 `{3,1,1,2}`：

```
2 3 1 1        row i 中 b[k] 的系数 = a[(k - i - 1) mod 4]
1 2 3 1
1 1 2 3
3 1 1 2
```

逐行核对可得通式：

```
z[i] = Σ_k  a[(k - i - 1) mod 4] · y[k]
```

代码里用 `(k - i + 3) & 3` 实现 `(k-i-1) mod 4`（避免负数取模）：

```c
for (i = 0; i < 4; i++) {
    unsigned int s = 0;
    for (k = 0; k < 4; k++)
        s ^= aes_8bit_mul_mod_0x11B(x[(k - i + 3) & 3], y[k]);
    r[i] = (unsigned char)s;
}
memcpy(z, r, 4);   // 用临时 r，允许 z 与 x/y 同地址（原地运算）
```

同一通式对逆系数 `{0x0B,0x0D,0x09,0x0E}` 自动给出 `aes.txt` 中的逆矩阵
（E B D 9 / 9 E B D / …），无需另写。**注意**：因为加密用到本函数，它必须正确，
否则三个密文都对不上——这也是密文一致即说明本函数正确的原因。

### 3. `ByteSubInverse`

`ByteSub` 查 `sbox`，逆操作查 `sbox_inverse`：

```c
for (i = 0; i < n; i++)
    p[i] = sbox_inverse[p[i]];
```

### 4. `ShiftRowInverse`

`ShiftRow` 把第 i 行循环**左**移 i 字节，逆操作循环**右**移 i 字节（用已有的 `ror_a_row`）：

```c
for (i = 1; i < 4; i++)
    ror_a_row(p + i*4, i);
```

### 5. `MixColumnInverse`：T∘L_a 的逆

正向 `MixColumn(do_mul=1) = T ∘ L_a`，其逆为

```
(T ∘ L_a)⁻¹ = L_a⁻¹ ∘ T⁻¹ = L_{a⁻¹} ∘ T      （T、L 都自逆/可逆）
```

即“先转置，再逐列乘 a⁻¹”。把它落到字节操作上：转置后的第 j 列恰好是原矩阵的**第 j 行**，
于是实现为“取第 j 行 → 乘 a⁻¹ → 放到第 j 列”：

```c
for (j = 0; j < 4; j++) {
    memcpy(b, p + j*4, 4);                 // b = 第 j 行
    if (do_mul)
        aes_polynomial_mul(a, b, b);       // b = a⁻¹ · b
    put_column(b, (unsigned char *)t, j);  // 第 j 列 = b
}
memcpy(p, t, 16);
```

- `do_mul=0` 时退化为纯转置，与加密里 `MixColumnInverse(a,0)` 的用法一致；
- 这个写法与 `aes.txt` 描述的“按列优先排成矩阵 m，算 t=A·m”完全等价。

>踩坑记录：`put_column(p, q, j)` 的语义是 `q[i*4+j]=p[i]`，**源在前、目的矩阵在后**。
>最初误写成 `put_column(t, b, j)`，把 16 字节写进只有 4 字节的 `b`，造成栈溢出段错误。
>改回 `put_column(b, t, j)` 后正常。

### 6. `aes_decrypt`：逐轮逆序

把 `aes_encrypt` 每一轮的 5 个步骤**逆序**、且每步**取逆**：

| 正向（轮 i） | 逆向（轮 i） |
|---|---|
| ByteSub | AddRoundKey(Kᵢ) |
| 转置 MixColumnInverse(a,0) | 逆 MixColumn：i<R 用 `MixColumnInverse(a⁻¹,1)`；i=R 用 `MixColumn(a,0)`（转置） |
| ShiftRow | ShiftRowInverse |
| MixColumn(a, do_mul) | 转置 `MixColumn(a,0)` |
| AddRoundKey(Kᵢ) | ByteSubInverse |

外层轮序从 `key_rounds` 倒到 1，最后再 `AddRoundKey(K₀)` 抵消第 0 轮加密的白化：

```c
unsigned char a[4]    = {0x03,0x01,0x01,0x02};  // 仅用于 do_mul=0 的转置
unsigned char ainv[4] = {0x0B,0x0D,0x09,0x0E};  // 逆变换多项式
memcpy(matrix, bufin, 16);
for (i = key_rounds; i >= 1; i--) {
    AddRoundKey(matrix, key + i*16);
    if (i != key_rounds) MixColumnInverse(matrix, ainv, 1);
    else                 MixColumn(matrix, a, 0);   // 末轮逆 = 转置
    ShiftRowInverse(matrix);
    MixColumn(matrix, a, 0);                         // 逆掉正向那次转置
    ByteSubInverse(matrix, 16);
}
AddRoundKey(matrix, key);
memcpy(bufout, matrix, 16);
```

正确性（一轮）可逐步验证：

```
设密文段 D = AddRoundKey(MixColumn_mul(ShiftRow(T(ByteSub(S)))), Kᵢ)
AddRoundKey(D,Kᵢ)            → MixColumn_mul(ShiftRow(T(ByteSub(S))))
MixColumnInverse(·,a⁻¹,1)   → ShiftRow(T(ByteSub(S)))        // L_{a⁻¹}∘T ∘ T∘L_a = I
ShiftRowInverse             → T(ByteSub(S))
MixColumn(·,0)=T            → ByteSub(S)
ByteSubInverse              → S
```

## 四、对 `MyAes.c` 的改动小结

1. 删除了 `#ifdef _MSC_VER … #pragma comment(lib,"aes_lib.lib") … #endif`；
2. 在 `main()` 之前补齐了上述 6 个函数的实现（均只调用文件内已有的工具函数
   `aes_8bit_mul_mod_0x11B`、`ror_a_row`、`put_column`、`AddRoundKey`、`MixColumn` 等，
   及全局数组 `sbox` / `sbox_inverse`、全局变量 `key_rounds`）。

无其它改动，输出与原版逐字节一致。
