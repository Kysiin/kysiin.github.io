# Enigma 破解题解答说明

## 一、题目目标

模拟图灵破解 Enigma 的过程。已知：

- **接线板 (plugboard)**：`AB CD EF GH IJ KL MN OP QR ST`（固定）
- **内部环设置 (ring setting)**：`UJZ`（从左到右，固定）
- 从 5 个可选齿轮中**任取 3 个并排序**（齿轮排列 `rotor`）以及它们的**外部初始设置** `key`（3 个字母）是未知的。

给定密文 `cipher` 与明文中必含的关键词 `key_word`，**穷举** `rotor`（齿轮编号排列）和 `key`（外部设置），逐一解密，若解密结果包含 `key_word`，就输出 `rotor`、`key`、`plain`。

样例：

```
输入:  PLMXWLXGHDULWUDTTOEHHXZIRIXXWVMTJ
       LAZYDOG
输出:  531
       YUM
       AQUICKBROWNFOXJUMPSOVERTHELAZYDOG
```

实测程序输出与样例完全一致，运行约 0.7s。

## 二、第 1 空：Enigma 加/解密引擎

Enigma 的关键性质：由于**反射器**和**接线板**都是对合映射（自己是自己的逆），所以**加密和解密是同一个过程**——把密文再过一遍机器就得到明文。

### 单个字母的信号路径

```
键盘 → 接线板 → 右齿轮 → 中齿轮 → 左齿轮 → 反射器
                                              ↓
灯盘 ← 接线板 ← 右齿轮 ← 中齿轮 ← 左齿轮 ←──────┘
```

### 1. 单齿轮正/反向通过

齿轮当前转动位置 `pos` 和环设置 `ring` 共同造成一个偏移 `shift = (pos - ring) mod 26`。信号进入齿轮时按 `shift` 平移找到实际触点，经内部接线后再平移回来：

```c
int rotor_forward(const char *wire, int pos, int ringv, int c){
    int shift = (pos - ringv + 26) % 26;
    int in    = (c + shift) % 26;     // 进入齿轮的实际触点
    int out   = wire[in] - 'A';       // 经内部接线
    return (out - shift + 26) % 26;   // 折算回外部触点
}
```

反向（经反射器之后）走的是同样公式，但用接线的**逆映射** `inv`。`make_inverse()` 负责求逆：若 `wire[i]=X`，则 `inv[X]=i` 对应的字母。

### 2. 接线板 `set_plugboard()`

把形如 `"AB CD EF"` 的字符串解析成对合映射：`plugboard[A]=B`、`plugboard[B]=A`，其余字母映射到自身。

### 3. 步进机构（最易错的地方）—— 双步进 (double-stepping)

每加密一个字母**之前**，齿轮先转动：

- **右齿轮**每次必转；
- 当右齿轮处于其“进位位置”时，带动**中齿轮**转一格；
- 当中齿轮处于其“进位位置”时，中齿轮和**左齿轮**同时转一格（这就是真实 Enigma 的“双步进”现象）。

```c
int mid_at   = (pos[1] == notch[1]);
int right_at = (pos[2] == notch[2]);
if (mid_at)   { pos[0]++; pos[1]++; }   // 中齿轮带动左齿轮(双步进)
if (right_at) {           pos[1]++; }   // 右齿轮带动中齿轮
pos[2]++;                               // 右齿轮每次必转   (均 mod 26)
```

**进位位置的换算**：题目给的 `step_char = "RFWKA"` 是“进位**发生后**窗口里显示的字母”（口诀 Royal Flags Wave Kings Above）。真正触发进位的**当前位置**是它的**前一个字母**，所以：

```c
notch[i] = (step_char[rotor_no[i]-'1'] - 'A' - 1 + 26) % 26;
```

>这一点 `-1` 至关重要：若直接用 `step_char` 本身做进位位置，样例就对不上。

### 4. 整串加/解密 `enigma()`

按上面流程对 `cipher` 每个字母依次：步进 → 接线板 → 右中左正向 → 反射器 → 左中右反向 → 接线板，写入 `plain`。`pos[0/1/2]` 初值取自 `key` 的 3 个字母。

## 三、第 2 空：穷举破解

```c
set_plugboard(init_plug);     // 已知接线板
gets(cipher);  gets(key_word);

for a,b,d in 0..4:            // 三层循环选 3 个齿轮(左/中/右)
    if 有重复 continue;       // 同一齿轮不能用两次  ->  P(5,3)=60 种排列
    init_rotor = "(a+1)(b+1)(d+1)";
    for k0,k1,k2 in 'A'..'Z': // 外部设置 key, 26^3 = 17576 种
        init_key = k0k1k2;
        enigma(init_rotor, init_ring, init_key, cipher, plain);
        if (strstr(plain, key_word)) {   // 明文含关键词 -> 命中
            puts(init_rotor); puts(init_key); puts(plain);
            goto done;        // 用 goto 跳出, 让程序正常 return 0
        }
```

- 搜索空间共 `60 × 17576 ≈ 1.05×10⁶` 种组合，C 语言下不到 1 秒，无超时风险。
- 找到解后用 `goto done;` 跳出（**不能** `exit(0)`，否则判题超时）。
- 齿轮编号字符 `'1'..'5'` 与数据表下标的换算：`rotor_table[编号-'1']`、`step_char[编号-'1']`。

## 四、编译与验证

```bash
gcc -O2 -o enigma enigma.c
printf 'PLMXWLXGHDULWUDTTOEHHXZIRIXXWVMTJ\nLAZYDOG\n' | ./enigma
# 输出:
# 531
# YUM
# AQUICKBROWNFOXJUMPSOVERTHELAZYDOG
```

（`gcc` 会对 `gets` 报 warning，属正常——本题要求用 `gets()`，不影响结果。）

## 五、易错点小结

1. **步进的 `-1` 换算**：`step_char` 是进位后的窗口字母，触发位置要减 1。
2. **双步进**：中齿轮在进位位置时，中、左齿轮同时转。
3. **环设置与位置的合并偏移** `(pos - ring) mod 26`，正反向都要正确折算回去。
4. 反向通过齿轮要用**逆接线**。
5. 收尾用 `goto done;` 而非 `exit(0)`。
