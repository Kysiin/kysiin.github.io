| # | 选题 | 覆盖课程内容 | 难度 | 工作量 | 视觉冲击 | 风险 | 评优潜力 |
|---|---|---|---|---|---|---|---|
| **A** | **基于质点-弹簧模型的布料动画与碰撞响应** | 布料动画、碰撞检测（+变形动画：撕裂；+粒子系统：风场） | ★★★☆ | 中高（约 1500 行 C++） | 强 | 中低 | 高 |

| C | 关节动画：骨骼 + IK + 线性混合蒙皮 | 关节动画、变形动画 | ★★★ | 中（约 1200 行） | 中强 | 中（需要模型与绑定） | 中高 |
| D | 三维 Morphing（网格对应 + 顶点插值/Laplacian） | 三维 Morphing | ★★★★☆ | 高 | 中 | 高（对应关系难做稳） | 中 |
| E | 群组动画：Boids + 避障 + 领队跟随 | 群组动画、碰撞检测 | ★★☆ | 中低（约 700 行） | 中 | 低 | 中低（偏单薄） |

### 为什么不选 B/C/D/E

- **B**：效果最炸，但 SPH 参数（h、刚度、粘性、CFL）非常吃经验，Marching Cubes 的网格规模与实时性难兼顾，容易陷入「调不出来」。
- **C**：需要一套带骨骼的模型和蒙皮权重，模型来源与绑定本身就是额外工作；且和「布料/碰撞」相比，可量化的实验少。
- **D**：三维对应关系（尤其非等拓扑）是研究级问题，课程设计里很难做得漂亮。
- **E**：Boids 三个规则半小时就能写完，作为课程设计偏单薄，答辩时不好讲深度。

## 2. 推荐选题

### 题目

**《基于质点-弹簧模型的布料动画与碰撞响应——实时仿真、交互与定量分析》**

英文：*Cloth Animation with Mass-Spring Model and Collision Response: Real-time Simulation, Interaction and Quantitative Analysis*

### 一句话概括

用质点-弹簧（Mass-Spring）网格建模布料，实现「显式积分」与「Verlet + 约束投影（PBD）」两套求解器，加入球体/地面/盒体碰撞与摩擦响应，配合实时 OpenGL 渲染、鼠标交互与离线帧导出，最后用统一实验框架对比两套求解器的稳定性、刚度表现与性能。

### 难度定位

- 比参考论文高：三维、实时、有碰撞检测、有双求解器对比、有定量实验、报告有曲线和数据表。
- 但不碰科研级问题：不做自碰撞的严格连续检测（做成可开关的近似方案）、不做流体/多相耦合、不做真实布料本构（用弹簧近似即可）。
- 单人可在 **6 个阶段内完成**，每个阶段都有可运行产物，不会出现「最后一周才发现跑不起来」。

### 覆盖的知识点（对应课程章节）

| 课程内容 | 在本项目中的落点 |
|---|---|
| 布料动画 | 核心：质点-弹簧网格、结构/剪切/弯曲弹簧、风场、阻尼、撕裂 |
| 碰撞检测 | 核心：球体解析检测、地面平面、AABB 盒；可选的顶点-三角形自碰撞（空间哈希加速） |
| 变形动画 | 加分：布料撕裂导致的拓扑变化与形变 |
| 粒子系统 | 加分：风场可视化粒子 / 布料与粒子耦合（可选，时间够再做） |
| 隐函数曲面 | 不涉及（如需要，可把碰撞体换成隐式球/超椭球求交，作为扩展） |

### 3.3 物理模型

**质点-弹簧网格**：`N×N` 个质点（默认 41×41=1600），静止边长 `h = L/(N-1)`。

弹簧三类（每类都参与，权重可调）：

| 类型 | 连接 | 作用 | 默认刚度 |
|---|---|---|---|
| 结构弹簧 | (i,j)-(i+1,j)、(i,j)-(i,j+1) | 抗拉伸 | k_s |
| 剪切弹簧 | 两条对角线 | 抗剪切 | 0.6·k_s |
| 弯曲弹簧 | (i,j)-(i+2,j)、(i,j)-(i,j+2) | 抗弯曲、褶皱自然 | 0.1·k_s |

受力：

```
F_spring = -k (|d| - L0) * d/|d| - c_d * (v_rel · d̂) d̂      （胡克 + 阻尼）
F_gravity = m g
F_wind    = k_w * A * (n · v_wind) * n                        （面元气动阻力，按三角形法线）
```

**两套求解器（同一份弹簧数据、同一个渲染器，便于对比）**：

1. **显式弹簧力 + 半隐式欧拉**：`v += F/m·dt; x += v·dt`，固定子步（dt=1/600，10 子步/帧）。
   优点：物理意义直白，能讲清「力」；缺点：刚度大时发散。
2. **Verlet 积分 + 约束投影（PBD）**：`x' = 2x - x_prev + a dt²`，再迭代距离约束
   `Δ = (|d|-L0)/ (w_a+w_b) * d̂`，刚度换算 `k' = 1-(1-k)^(1/n)`。
   优点：大刚度稳定、可加碰撞约束；缺点：需要解释约束投影的「人工刚度」。

>两套并存是本项目的**实验主线**：同一场景、同一参数下比较稳定性与视觉差异。

**撕裂（加分项）**：弹簧伸长率超过阈值时删除该弹簧；若某质点失去全部结构弹簧则删除质点与相邻三角形（拓扑变化 → 变形动画）。

### 3.4 碰撞检测与响应

| 碰撞体 | 检测 | 响应 |
|---|---|---|
| 球体 | `|p-c| < r` | 投影到球面 + 法向速度置零 + 切向摩擦（`v_t *= (1-μ)`） |
| 地面/墙 | `y < 0` 等平面约束 | 同上，投影到平面 |
| 旋转 AABB | 变换到盒体局部坐标后逐轴判断 | 取最小穿透轴投影 |
| 自碰撞（可选） | 空间哈希 + 顶点-三角形距离 < 厚度 | 位置修正 + 速度阻尼，迭代内处理 |

统计量：每帧最大穿透深度、穿透质点比例、碰撞响应次数 → 直接进报告表格。

### 3.5 渲染与交互

- 布料：三角形网格，逐顶点法线，双面光照，程序生成的棋盘/条纹纹理（也可加载 `assets/` 图片）。
- 场景：渐变天空、地面网格、布料在地面的投影阴影（沿光方向压扁绘制）。
- 相机：左键拖拽旋转、滚轮缩放、右键平移。
- 交互：鼠标抓取最近质点拖拽；`空格`暂停、`N`单步、`R`重置、`1-5`场景、`Tab`切换求解器、`W`线框、`P`截图、`F`开始/结束录制。
- HUD：参数（k、迭代次数、子步、风力、重力、摩擦）、FPS、粒子/弹簧数、最大拉伸率、最大穿透深度。

### 3.6 输出与交付

- 实时程序：`ClothLab.exe`（双击即用，含控制台日志）。
- 离线录制：`ClothLab.exe --record --scene flag --frames 600 --out data/flag` → 序列帧 → `tools/make_gif.py` → `report/figures/flag.gif` + 关键帧 PNG。
- 实验数据：`--bench` 模式批量跑参数组合，输出 `data/bench_*.csv`。
- 报告：`report/布料动画实验报告.docx`（+ PDF），图表全部由脚本从 CSV/帧生成，可复现。

>参考论文最大的问题是「只有效果图，没有数据」。我们用 6 组实验把「做出来了」升级成「分析过了」。

| 编号 | 实验 | 自变量 | 观测量 | 预期图表 |
|---|---|---|---|---|
| E1 | 两套求解器的稳定性边界 | 刚度 k（对数扫描）、子步数 | 最大边长误差、总能量、是否发散 | 双曲线图（误差-刚度）+ 发散临界点表 |

| E3 | 时间步长与子步 | dt、substeps | 帧耗时、最大穿透、稳定性 | 表格 |
| E4 | 碰撞响应质量 | 摩擦系数 μ、球体半径 | 穿透深度分布、滑落时间、包裹角 | 直方图 + 曲线 |

## 7. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 高刚度下显式积分发散 | 演示翻车 | 子步 + PBD 兜底；发散时 HUD 提示并自动降刚度 |
| 自碰撞慢 / 穿插 | 帧率掉、布料「穿自己」 | 空间哈希 + 厚度阈值；默认关闭，作为对比实验 |
| 布料与球体穿透 | 视觉穿帮 | 碰撞在约束迭代内多次投影；穿透深度实时统计 |
| 固定管线在高分屏缩放异常 | 画面模糊/错位 | 声明 DPI aware，按物理像素设 viewport |
| exe 在老师机器缺 DLL | 无法运行 | `-static` 链接；只依赖系统 DLL |
| 报告图表中文乱码 | 排版扣分 | matplotlib 指定 SimHei；或图内用英文标注 |
| 实验数据与报告不一致 | 可信度 | 所有图表由 `tools/make_figs.py` 从 `data/*.csv` 生成 |
