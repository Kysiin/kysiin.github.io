## 1 第 12 章 静电场
### 1.1 库仑定律与场强

| 名称        | 公式                                                                               | 适用条件 / 注意                                                                         |
| --------- | -------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| ★库仑定律（矢量） | $\boldsymbol{F}=\dfrac{1}{4\pi\varepsilon_0}\dfrac{q_1q_2}{r^2}\boldsymbol{e}_r$ | 真空、点电荷；$\boldsymbol{e}_r$ 由施力电荷指向受力电荷；同号斥、异号吸（矢量式自动含符号，别再加正负号）                    |
| ★点电荷场强    | $\boldsymbol{E}=\dfrac{1}{4\pi\varepsilon_0}\dfrac{q}{r^2}\boldsymbol{e}_r$      | $q$ 带符号代入，负电荷场强指向电荷本身                                                             |
| ★场强叠加     | $\boldsymbol{E}=\sum\boldsymbol{E}_i=\int\mathrm{d}\boldsymbol{E}$               | 矢量叠加，必须分解到坐标轴再求和；点电荷、连续带电体通用                                                      |
| 连续带电体微元   | $\mathrm{d}E=\dfrac{1}{4\pi\varepsilon_0}\dfrac{\mathrm{d}q}{r^2}$               | $\mathrm{d}q=\lambda\mathrm{d}l$（线）、$=\sigma\mathrm{d}S$（面）、$=\rho\mathrm{d}V$（体） |

### 1.2 典型带电体的场强

| 带电体          | 场强                                                                                           | 位置 / 条件                                                                                       |
| ------------ | -------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| ★无限长均匀带电直线   | $E=\dfrac{\lambda}{2\pi\varepsilon_0 r}$                                                     | 距线 $r$，方向垂直直线（正电向外）                                                                           |
| ★均匀带电圆环轴线    | $E=\dfrac{qx}{4\pi\varepsilon_0\left(R^2+x^2\right)^{3/2}}$                                  | 轴线上距圆心 $x$ 处，方向沿轴；圆心处 $E=0$                                                                   |
| ★均匀带电圆盘轴线    | $E=\dfrac{\sigma}{2\varepsilon_0}\left(1-\dfrac{x}{\sqrt{R^2+x^2}}\right)$                   | 轴线上距盘心 $x$ 处，方向沿轴；$x\ll R$ 退化为 $\dfrac{\sigma}{2\varepsilon_0}$                               |
| ★无限大均匀带电平面   | $E=\dfrac{\sigma}{2\varepsilon_0}$                                                           | 与距离无关；两面异号电荷 $\pm\sigma$ 的平行板**之间**为 $E=\dfrac{\sigma}{\varepsilon_0}$                        |
| 有限长均匀带电直线    | $E=\dfrac{\lambda}{4\pi\varepsilon_0 r}\left(\cos\theta_1+\cos\theta_2\right)$               | 该点在直线中垂线上、距线 $r$；$\theta_1,\theta_2$ 为两端点与场点连线跟直线的夹角。**无限长时 $\cos\theta_1+\cos\theta_2\to2$** |
| ★均匀带电球面（外）   | $E=\dfrac{Q}{4\pi\varepsilon_0 r^2}$                                                         | $r>R$，等效于电荷集中在球心                                                                              |
| ★均匀带电球面（内）   | $E=0$                                                                                        | $r<R$（球壳内无场）                                                                                  |
| ★均匀带电球体（内）   | $E=\dfrac{\rho r}{3\varepsilon_0}=\dfrac{Qr}{4\pi\varepsilon_0 R^3}$                         | $r<R$，与 $r$ 成正比                                                                               |
| ★均匀带电球体（外）   | $E=\dfrac{Q}{4\pi\varepsilon_0 r^2}$                                                         | $r>R$                                                                                         |
| 无限长均匀带电圆柱面/体 | 外：$E=\dfrac{\lambda}{2\pi\varepsilon_0 r}$；体（内）：$E=\dfrac{\lambda r}{2\pi\varepsilon_0 R^2}$ | 面内 $E=0$；注意与球的区别                                                                              |

### 1.3 通量、高斯定理、环流定理

| 名称       | 公式                                                                                            | 适用条件 / 注意                                                 |
| -------- | --------------------------------------------------------------------------------------------- | --------------------------------------------------------- |
| ★电通量     | $\Phi_e=\int\boldsymbol{E}\cdot\mathrm{d}\boldsymbol{S}$                                      | 闭合面约定**外法向为正**；出为正、进为负                                    |
| ★高斯定理    | $\oint_S\boldsymbol{E}\cdot\mathrm{d}\boldsymbol{S}=\dfrac{\sum q_{\text{内}}}{\varepsilon_0}$ | 永远成立；但**只在高对称时能反求 $E$**；面上 $E$ 与面外电荷无关的部分不成立，别写"面外电荷不产生场" |
| ★环流定理    | $\oint_L\boldsymbol{E}\cdot\mathrm{d}\boldsymbol{l}=0$                                        | 静电场是保守场；与路径无关                                             |
| ★电势差（定义） | $U_{AB}=U_A-U_B=\int_A^{B}\boldsymbol{E}\cdot\mathrm{d}\boldsymbol{l}$                        | 沿任意路径积分，结果与路径无关                                           |
### 1.4 电势与电势能

| 名称 | 公式 | 适用条件 / 注意 |
| --- | --- | --- |
| ★点电荷电势 | $U=\dfrac{q}{4\pi\varepsilon_0 r}$ | 取无穷远为零电势；$q$ 带符号 |
| ★电势叠加 | $U=\sum U_i=\int\dfrac{\mathrm{d}q}{4\pi\varepsilon_0 r}$ | 标量相加，直接带符号，不用分解 |
| ★电势零点 | 参考点处 $U=0$ | 有限带电体取无穷远；**无限大带电体或无限长导线不能取无穷远**，改取自身或有限距离处 |
| ★球面（壳）电势 | 外：$U=\dfrac{Q}{4\pi\varepsilon_0 r}$；内：$U=\dfrac{Q}{4\pi\varepsilon_0 R}$（处处相等，等于球面值） | $r<R$ 时球壳内无场，电势恒定 |
| ★球体电势 | 外：$U=\dfrac{Q}{4\pi\varepsilon_0 r}$；内：$U=\dfrac{Q}{8\pi\varepsilon_0R}\left(3-\dfrac{r^2}{R^2}\right)$ | 内部分段式，$r=R$ 处两式应相等（自检） |
| ★电势能 | $W=qU$ | $q$ 带符号；$W$ 是"电荷与场共有的能量" |
| ★电场力做功 | $W_{AB}=q\left(U_A-U_B\right)=qU_{AB}$ | 正电荷从高电势到低电势，电场力做正功 |
| ★由 $E$ 求 $U$ | $U_A=\int_A^{\text{参考点}}\boldsymbol{E}\cdot\mathrm{d}\boldsymbol{l}$ | 需分段积分；先定 $E(r)$ 的表达式！ |
| ★由 $U$ 求 $E$ | $E_l=-\dfrac{\partial U}{\partial l}$；$\boldsymbol{E}=-\nabla U$ | 沿 $l$ 方向的分量；电势降的方向就是 $E$ 的方向 |
| 电偶极子在场的能量 | $W=-\boldsymbol{p}\cdot\boldsymbol{E}$；$\boldsymbol{M}=\boldsymbol{p}\times\boldsymbol{E}$ | 均匀外场；$W$ 最小（最稳定）时 $\boldsymbol{p}\parallel\boldsymbol{E}$ |

## 2 第 13 章 导体与电介质
### 2.1 导体静电平衡

| 名称 | 公式 / 结论 | 适用条件 / 注意 |
| --- | --- | --- |
| ★平衡条件 | 内部 $\boldsymbol{E}=0$；表面 $E\perp$ 表面；整个导体等势 | 是所有导体题的第一步 |
| ★表面场强 | $E=\dfrac{\sigma}{\varepsilon_0}$ | 导体表面外侧；$\sigma$ 是**该点**面电荷密度（是 $\dfrac{\sigma}{2\varepsilon_0}$ 的两倍，因为单面电荷） |
| ★电荷分布 | 净电荷只分布在外表面；曲率大处 $\sigma$ 大 | 孤立导体；内部与空腔（无电荷时）均无净电荷 |
| ★腔内有电荷 $q$ | 内表面带 $-q$；外表面带 $Q+q$ | $Q$ 为导体原有净电荷 |
| ★接地 | 导体电势 $U=0$，其上电荷可增减 | 接地 ≠ "无电荷"，只保证 $U=0$ |
| 静电屏蔽 | 空腔无电荷：腔内 $E=0$ 且与外部隔离；腔内有电荷：外部场由外表面电荷决定 | 接地外壳可屏蔽"内部对外" |
### 2.2 电容与电容器

| 名称 | 公式 | 适用条件 / 注意 |
| --- | --- | --- |
| ★电容定义 | $C=\dfrac{Q}{U}$（$U$ 为两板电势差绝对值） | 与 $Q$、$U$ 无关，只由几何与介质决定 |
| ★平行板 | $C=\dfrac{\varepsilon_0\varepsilon_rS}{d}$ | 忽略边缘效应；真空取 $\varepsilon_r=1$ |
| ★球形电容器 | $C=\dfrac{4\pi\varepsilon_0\varepsilon_rab}{b-a}$ | 内半径 $a$、外半径 $b$ |
| ★孤立导体球 | $C=4\pi\varepsilon_0\varepsilon_rR$ | 相当于外极板在无穷远 |
| ★圆柱形电容器 | $C=\dfrac{2\pi\varepsilon_0\varepsilon_rl}{\ln\left(R_2/R_1\right)}$ | 同轴圆柱，长 $l$，忽略端部 |
| ★串联 | $\dfrac{1}{C}=\sum\dfrac{1}{C_i}$，$Q$ 相同 | 串联**电荷相同**、耐压相加 |
| ★并联 | $C=\sum C_i$，$U$ 相同 | 并联**电压相同**、容量相加 |
| ★能量 | $W_e=\dfrac{Q^2}{2C}=\dfrac{1}{2}CU^2=\dfrac{1}{2}QU$ | 三式等价，看已知量选 |
| ★能量密度 | $w_e=\dfrac{1}{2}\varepsilon_0E^2$（真空），$w_e=\dfrac{1}{2}\varepsilon E^2=\dfrac{1}{2}\boldsymbol{D}\cdot\boldsymbol{E}$ | 单位 $\mathrm{J/m^3}$；$W_e=\int w_e\mathrm{d}V$ |
### 2.3 电介质

| 名称 | 公式 | 适用条件 / 注意 |
| --- | --- | --- |
| ★有介质的高斯定理 | $\oint_S\boldsymbol{D}\cdot\mathrm{d}\boldsymbol{S}=\sum q_{0(\text{内})}$ | 右端**只含自由电荷**；$\boldsymbol{D}$ 线起于自由正电荷、止于自由负电荷 |
| ★本构关系 | $\boldsymbol{D}=\varepsilon_0\varepsilon_r\boldsymbol{E}=\varepsilon\boldsymbol{E}$ | 各向同性线性介质；$\varepsilon_r$ 无量纲 |
| 极化强度 | $\boldsymbol{P}=\dfrac{\sum\boldsymbol{p}_i}{\Delta V}$；$\boldsymbol{D}=\varepsilon_0\boldsymbol{E}+\boldsymbol{P}$ | $\sigma'=\boldsymbol{P}\cdot\boldsymbol{e}_n=P\cos\theta$ |
| ★介质中库仑定律 | $E=\dfrac{q}{4\pi\varepsilon_0\varepsilon_rr^2}$ | 无限大均匀介质中；**不是** $\varepsilon_r^2$ |
| 极化率 | $\chi_e=\varepsilon_r-1$ | 无量纲 |
| ★求电容三步法 | 设 $Q$ → 求 $\boldsymbol{D}$（自由电荷高斯定理）→ $E=D/\varepsilon$ → $U=\int E\,\mathrm{d}l$ → $C=Q/U$ | 通用流程，务必按顺序写 |

## 3 第 14 章 电流和磁场
### 3.1 电流与欧姆定律

| 名称 | 公式 | 适用条件 / 注意 |
| --- | --- | --- |
| ★电流 | $I=\dfrac{\mathrm{d}q}{\mathrm{d}t}$ | 标量，有正负之分（与所选方向比较） |
| ★电流密度 | $\boldsymbol{j}=nq\boldsymbol{v}_d$；$I=\int_S\boldsymbol{j}\cdot\mathrm{d}\boldsymbol{S}$ | 矢量，方向为正电荷运动方向 |
| ★欧姆定律（微分） | $\boldsymbol{j}=\sigma\boldsymbol{E}$ | 各向同性导体；$\sigma$ 电导率 |
| ★电阻 | $R=\dfrac{\rho l}{S}=\dfrac{l}{\sigma S}$ | $\rho$ 为电阻率，与体电荷密度符号冲突，看上下文 |
| 闭合电路 | $I=\dfrac{\varepsilon_{\text{源}}}{R+r}$；$U=\varepsilon_{\text{源}}-Ir$ | $\varepsilon_{\text{源}}$ 为电动势，端电压小于电动势 |
| 电动势 | $\varepsilon_{\text{源}}=\dfrac{W_{\text{非静电力}}}{q}$ | 非静电力做功/电荷，标量 |
### 3.2 磁感应强度与毕奥-萨伐尔定律

| 名称        | 公式                                                                                                           | 适用条件 / 注意                                                    |
| --------- | ------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------ |
| ★磁力定义     | $\boldsymbol{F}=q\boldsymbol{v}\times\boldsymbol{B}$                                                         | 运动电荷；$F$ 最大时 $B=F/(qv)$                                      |
| ★磁通量      | $\Phi_m=\int\boldsymbol{B}\cdot\mathrm{d}\boldsymbol{S}$                                                     | 单位 Wb                                                        |
| ★磁场高斯定理   | $\oint_S\boldsymbol{B}\cdot\mathrm{d}\boldsymbol{S}=0$                                                       | 磁场无源；$\boldsymbol{B}$ 线闭合                                    |
| ★毕奥-萨伐尔   | $\mathrm{d}\boldsymbol{B}=\dfrac{\mu_0}{4\pi}\dfrac{I\,\mathrm{d}\boldsymbol{l}\times\boldsymbol{e}_r}{r^2}$ | $\mathrm{d}\boldsymbol{l}$ 沿电流方向，$\boldsymbol{e}_r$ 由电流元指向场点 |
| ★无限长直导线   | $B=\dfrac{\mu_0I}{2\pi a}$                                                                                   | 距导线 $a$；方向由右手螺旋（拇指电流→四指磁场）                                   |
| ★有限长直导线   | $B=\dfrac{\mu_0I}{4\pi a}\left(\cos\theta_1+\cos\theta_2\right)$                                             | $\theta$ 为端点连线与导线夹角；一端无限延伸取 $\cos\theta=0$                   |
| ★圆电流圆心    | $B=\dfrac{\mu_0I}{2R}$                                                                                       | 圆心处；轴线上为 $\dfrac{\mu_0IR^2}{2\left(R^2+x^2\right)^{3/2}}$    |
| ★载流圆弧圆心   | $B=\dfrac{\mu_0I\theta}{4\pi R}$                                                                             | $\theta$ 为圆心角（弧度）；整圆取 $\theta=2\pi$ 得 $\dfrac{\mu_0I}{2R}$   |
| ★密绕长螺线管内部 | $B=\mu_0nI=\dfrac{\mu_0NI}{L}$                                                                               | 无限长近似；外部 $B\approx0$；端部约为一半                                  |
| ★螺绕环内部    | $B=\dfrac{\mu_0NI}{2\pi r}$                                                                                  | 环内各处不同（与 $r$ 有关）；环外近似 $0$                                    |
| 运动电荷      | $\boldsymbol{B}=\dfrac{\mu_0}{4\pi}\dfrac{q\boldsymbol{v}\times\boldsymbol{e}_r}{r^2}$                       | 非相对论                                                         |
### 3.3 安培环路定理与磁力

| 名称          | 公式                                                                            | 适用条件 / 注意                                                                   |
| ----------- | ----------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| ★安培环路定理     | $\oint_L\boldsymbol{B}\cdot\mathrm{d}\boldsymbol{l}=\mu_0\sum I_{\text{内}}$   | 普遍成立；求 $B$ 需高对称；电流方向与环路绕向成右手螺旋取正                                            |
| ★载流圆柱导体     | 内：$B=\dfrac{\mu_0Ir}{2\pi R^2}$；外：$B=\dfrac{\mu_0I}{2\pi r}$                  | 均匀分布电流；内部与 $r$ 成正比                                                          |
| ★安培力        | $\mathrm{d}\boldsymbol{F}=I\,\mathrm{d}\boldsymbol{l}\times\boldsymbol{B}$    | 匀强场中直导线 $\boldsymbol{F}=I\boldsymbol{l}\times\boldsymbol{B}$，$l$ 取电流方向的有向线段 |
| ★匀强场中任意弯曲导线 | $\boldsymbol{F}=I\boldsymbol{L}\times\boldsymbol{B}$（$\boldsymbol{L}$ 为起点到终点） | 只有无限长/闭合等情形才需要单独讨论                                                          |
| ★平行直导线间的作用力 | $\dfrac{F}{l}=\dfrac{\mu_0I_1I_2}{2\pi d}$                                    | 单位长度；电流同向相吸、反向相斥                                                            |
| ★磁矩         | $\boldsymbol{m}=I\boldsymbol{S}=IS\boldsymbol{e}_n$                           | $\boldsymbol{e}_n$ 与电流成右手螺旋                                                 |
| ★磁力矩        | $\boldsymbol{M}=\boldsymbol{m}\times\boldsymbol{B}$                           | 匀强场；$M=ISB\sin\theta$                                                       |
| 磁偶极子势能      | $W=-\boldsymbol{m}\cdot\boldsymbol{B}$                                        | 稳定平衡 $\boldsymbol{m}\parallel\boldsymbol{B}$                                |
| ★洛伦兹力圆周运动   | $R=\dfrac{mv}{qB}$；$T=\dfrac{2\pi m}{qB}$                                     | $v\perp B$；周期与速率无关（回旋加速器原理）                                                 |
| 速度选择器       | $v=\dfrac{E}{B}$                                                              | 电场力与洛伦兹力平衡                                                                  |
